# 패턴 색인

만들려는 **상호작용**으로 찾는다. 사례 사이트는 카드의 패턴 칸에서 빌드가 모은다. 패턴마다 사례 카드는 `catalog.json`의 `patterns[].sites`나 보관함 패턴 탭에서 본다. 레이어 대응은 [docs/11](../docs/11-레이어-설정-시스템-설계.md) 용어로 적는다. 2026-09-30에 카드 7장을 Aside로 직접 열어 본 뒤 설명·레이어 대응·검수할 점을 관찰에 맞게 고쳤다. 카드가 늘면 새 패턴은 그때 추가하고, 쓰는 카드가 없는 패턴은 지운다.

### `desktop-os` — 데스크톱 OS 은유

작업물·정보를 창·아이콘·폴더로 연다. 방문자가 이미 아는 조작(아이콘 열기, 창 닫기·끌기)을 탐색으로 쓴다. 참고 사례는 아이콘 하나를 누르면 정보 창이 여러 개 동시에 열리고 창 제목 줄을 끌 수 있었다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 작업물이 많은 개인 포트폴리오, 레트로·장난스러운 콘셉트 |
| 패밀리 | 새 패턴 |
| 레이어 대응 | 배경화면 · 아이콘 그리드 · 창 프레임 · 창 내용 · 독(작업 표시줄) — 창 크기·처음 위치(창마다 다르게 열지)·열림 모션·아이콘 간격·아이콘 크기와 이름표 크기 |
| 검수할 점 | 아이콘에 Tab·Enter로 창이 열리는지, **Escape와 키보드로 창 닫기**(참고 사례는 마우스 전용 닫기 점), 창이 겹칠 때 뒤 창을 눌러 앞으로 오는지와 읽기 순서, 아이콘을 끌 수 있는 것처럼 보이는데 못 끄는 어긋남 없애기, 첫 로딩(이미지 수십 장이면 수십 초), 모바일에서는 창 대신 전체 화면 |

### `drive-to-explore` — 게임형 공간 탐색

방문자가 캐릭터·탈것을 움직여 공간을 돌아다니며 작업물을 발견한다. 참고 사례는 방향키·WASD로 차를 몰아 표지를 지나가고, Escape로 메뉴를 열고 닫는다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 기억에 남아야 하는 개인·스튜디오 소개, 게임 감각이 브랜드인 곳 |
| 패밀리 | A' |
| 레이어 대응 | 월드(지형·오브젝트) · 플레이어 · 안내 표지 · HUD · 메뉴(조작 안내·Respawn) · 입장 연출 · 목록 대체 화면 — 이동 속도·카메라 거리·표지 문구·조작 안내 문구 |
| 검수할 점 | 키보드·터치 조작과 조작 안내, **조작 없이 작업 목록으로 바로 가는 경로(참고 사례에는 없어서 우리가 채워야 함)**, 길을 잃었을 때 Respawn·Unstuck 같은 복귀 버튼, Escape로 메뉴 열기·닫기, 일반 Tab 탐색이 안 되는 점과 동작 줄이기 대응 없음의 보완, 첫 로딩(참고 사례는 약 20초·번들 약 5MB)과 로딩 화면 |

### `moodboard-canvas` — 자유 배치 무드보드

작업 이미지를 격자 대신 자유롭게 흩어 놓고, 끌거나 훑으며 본다. 참고 사례의 무드보드는 작업을 전시하는 용도가 아니라, 흩어 놓은 스티커를 끌어 빈 포스터 위에 올려 **나만의 포스터를 만드는 참여형 놀이**였다(작품 목록은 타일 벽 페이지가 따로 맡았다).

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 이미지 중심 작업(일러스트·사진·브랜딩) |
| 패밀리 | 새 패턴 |
| 레이어 대응 | 캔버스 배경(빈 포스터 크기·색) · 조각 풀(스티커·작업 카드의 위치·회전·크기) · 끌기 동작(드롭 범위·겹침 순서·놓을 때 효과) · 안내 문구 · 상세 오버레이 — 흩어짐 정도·카드 크기·끌기 관성 |
| 검수할 점 | **끌지 않고도 모든 조각·작업에 닿는 목록형 대체 경로**(참고 사례는 키보드로 스티커에 닿지 않았다), 조각마다 `alt` 슬롯(참고 사례는 104장 모두 비어 있었다), 초기화·되돌리기 버튼(참고 사례에 없음), 조각이 겹칠 때 읽기 순서와 포커스, 390px에서 목록형 대체 |

### `hand-drawn` — 손그림 표현

글자·선·버튼을 손으로 그린 질감으로 표현해 작가의 손맛을 첫인상으로 쓴다. 참고 사례는 길거리 한 장면을 통째로 그려 놓고 **그림 속 물건(표지판·소화전·비둘기)이 곧 메뉴 링크**였으며, 호버 때 그림 한 조각(차)이 움직였다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 일러스트레이터·작가 포트폴리오 |
| 패밀리 | 새 패턴 |
| 레이어 대응 | 장면 배경 · 그림 링크(조각 이미지·위치·회전·이동할 주소·`alt` 슬롯) · 손글씨 문구(폰트·문구 파라미터) · 호버 모션(움직일 조각·길이·돌아올지) · 안내 말풍선 — 장식 이미지 교체·흔들림 모션·질감 불투명도 |
| 검수할 점 | 문구를 손글씨 이미지에 굽지 않기(참고 사례는 제목·메뉴·말풍선이 모두 `alt` 없는 그림이어서 스크린리더로는 읽을 글이 거의 없었다), 그림 링크에 Tab으로 닿고 이름이 있는지(참고 사례는 포커스가 body에 머묾), 호버 모션이 한 번 지나가고 돌아오지 않는 구조를 피하기, 대비 |

### `illustration-hero` — 일러스트 히어로 모션

첫 화면을 큰 일러스트와 그 일러스트의 움직임으로 채운다. 참고 사례는 광대 일러스트가 가만히 있어도 조금씩 흔들리고(그림 조각 100개 중 34개), 스크롤하면 층마다 다른 속도로 움직이며, 메뉴는 현수막 끄는 비행기 그림이었다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 일러스트·애니메이션 작가, 캐릭터 IP |
| 패밀리 | 새 패턴 |
| 레이어 대응 | 히어로 일러스트(부위별 분리) · 배경(스크롤에 바뀌는 장면) · 메뉴 소품 · 연락처 배지 · 흐르는 작품 타일 줄 · 스크롤 안내 — 부위별 모션 강도·반복 속도·포인터 반응·스크롤 층 속도 비율 |
| 검수할 점 | **동작 줄이기에서 정지 프레임과 전체 끄기 스위치**(참고 사례는 끄는 경로가 없어 보였다), 첫 화면 로딩 용량(참고 사례는 그림 100개·첫 내용 약 3초), 계속 흐르는 타일 줄을 누르기 쉬운지와 멈춤, 메뉴 글자가 그림이라 읽히는지, Tab 접근 |

### `expand-gallery` — 클릭하면 펼쳐지는 갤러리

작은 사진을 누르면 그 자리에서 크게 펼쳐지거나 이어진 사진이 드러난다. 참고 사례는 사진을 누르면 **그 자리에서 4장으로 갈라지며 격자가 재배치**되고(다시 누르면 또 갈라짐), 호버 때 나오는 ↗ 버튼으로 전체 화면 라이트박스(이전·다음·닫기)를 따로 연다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 사진·공간·제품 작업 |
| 패밀리 | 새 패턴 |
| 레이어 대응 | 썸네일 격자(마스크 모양·간격) · 갈라지기(장수·최대 깊이·접기 버튼) · 호버 버튼 · 라이트박스(배경 흐림·버튼 위치·키) · 머리글 버튼 — 펼침 크기·전환 길이·곡선·캡션 위치 |
| 검수할 점 | **갈라진 상태를 되돌리는 방법**(참고 사례는 Escape·재클릭으로 안 돌아왔다), Escape·←·→로 라이트박스 조작과 닫은 뒤 포커스 복귀(참고 사례는 잘 됨), 뒤로 가기(참고 사례는 주소가 안 바뀌어 사이트 이탈), 같은 이름의 버튼이 둘이 되지 않게 구분, 호버 전용 버튼의 터치 대체, 동작 줄이기에서 즉시 전환, 큰 이미지 지연 로드 |

### `video-tile-catalog` — 루프 영상 타일 카탈로그

결과물을 정지 이미지 대신 **짧은 루프 영상 타일**로 벽돌처럼 깔아 훑어 고르게 하고, 타일을 누르면 큰 미리보기 상세가 덮인다. 참고 사례는 화면에 들어온 타일만 재생하고, 상세를 주소 파라미터(`?prompt=…`)로 열어 Escape·뒤로 가기로 닫힌다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 템플릿·프롬프트·배경 모음처럼 움직이는 결과물을 고르는 화면, 브랜드·제품 랜딩의 작업 예시 모음 |
| 패밀리 | D |
| 레이어 대응 | 제목·카테고리 알약 · 타일 벽(열 수·간격·타일 비율) · 타일 영상(재생 조건·포스터) · 상세 오버레이(영상·이름·분류·좋아요) — 열 수·재생 시작 거리·상세 전환 길이·알약 목록 |
| 검수할 점 | 화면 밖 타일은 멈춘 포스터인지와 전체 영상 용량(참고 사례는 첫 내용 약 3.6초), 타일 본체에 Tab으로 닿는지(참고 사례는 복사·좋아요 버튼만 잡혔다), 상세를 Escape·뒤로 가기·← 버튼으로 닫기, 카테고리 필터가 실제로 타일을 바꾸는지, **동작 줄이기에서 영상 자동 재생 정지**(참고 사례는 끄는지 확인 못 함), 터치 기기에서 호버 없이 미리보기 |
