노션에서 가져오는 법

노션 Instagram 리서치 DB(collection://02db5062-22f7-41cb-9741-3b4b712b732c)가 수집함이고, 이 폴더가 정리본이다.

  1. 사용자가 행의 Tags에 인터랙티브 참고를 붙인다.
  2. "레퍼런스 가져와"라고 하면 에이전트가 노션 커넥터로 태그가 붙은 행을 조회한다(rows 모드 Tags enum_contains 필터). 막히면 뷰 전체를 읽고 걸러 낸다.
  3. catalog.json의 notion·url과 비교해 새 행과 새 사이트만 고른다. 같은 자료가 DM과 Message Request로 두 번 들어온 행이 있으니 중복 행 id도 카드에 함께 적는다.
  4. 행 본문에서 사이트 주소를 뽑는다. 한 행에 여러 사이트가 있을 수 있고, 그때는 카드마다 같은 노션 id를 적는다. 주소가 없는 행은 건너뛰고 보고한다. 단 리포스트(릴스·카루셀) 행은 원래 주소가 없으니, 캡션·캡처로 원본 사이트를 웹에서 찾아 5단계로 넘긴다. 못 찾으면 노션에 저장된 릴스 캡처로 ⏸ 카드를 쓰고 주소 칸에는 계정 프로필(https://www.instagram.com/<계정>/)이나 판매 페이지를 적는다. 노션 캡처 주소는 서명 URL이라 페이지를 읽고 5분 안에 받아야 한다. AI 생성 영상(글자 깨짐, 인스타그램 "AI 콘텐츠" 표시)은 실제 사이트가 아니므로 넣지 않는다.
  5. 사이트마다 Aside로 직접 연다: 입력 → 바뀌는 상태 → 피드백 → 되돌리기, 키보드·로딩 시간, 네트워크·DOM에서 보이는 기술 흔적. Aside 창은 데스크톱 크기(시작은 1440×900이고 도중에 바뀔 수 있어 캡처 때마다 innerWidth를 읽어 적는다)로 거의 고정이라 390px 배치와 동작 줄이기는 흉내 낼 수 없다. 스타일시트·스크립트에서 읽은 근거를 (추정)으로 적고 확인 한계에 "실측 못 함"이라고 쓴다. Aside 캡처에는 오른쪽 가장자리(약 x=1258, y=152)에 Aside의 떠 있는 버튼이 찍힌다 — 사이트 UI가 아니다.
  6. 카드를 쓰고, 새 패턴이면 patterns.md에 추가한다. 캡처는 media/<사이트id>/에 긴 변 1280px webp 2장 이하, 녹화는 10초 이하 무음 webm 1개, 사이트당 합계 2MB 이하.
  7. pnpm references:build → pnpm check → 보관함을 같은 주소로 다시 게시한다. 노션에는 되쓰지 않는다.

노션 커넥터가 없는 세션(Codex 등)은 가져오기를 하지 않고 읽기만 한다. 커넥터가 끊겼으면 멈추고 /mcp 재연결을 안내한다.
