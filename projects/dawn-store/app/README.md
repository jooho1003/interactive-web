# 새벽 세 시 플레이어

Node.js 24에서 앱 폴더를 열고 실행한다.

```sh
pnpm install   # 저장소 루트에서 실행
pnpm run dev
```

왼쪽 위 **설정**에서 관람 환경을 바꾼다.

설정의 **작품 편집**에서 이 브라우저의 작품을 바로 꾸밀 수 있다. 제목, 장면 이미지, 폰트 스택, 색상, 자막·선택지·타임라인·컨트롤 위치, BGM을 바꾸고 JSON으로 백업할 수 있다. 이미지와 오디오는 브라우저 저장을 위해 1.8MB 이하 파일을 권장한다. 기본 장면과 BGM은 반복하지 않으며, 장면이 끝나면 `이 장면 다시 보기`를 선택한다.

- **기본**: 작품 기본 음량, 보통 자막, 기기의 움직임 설정을 따른다.
- **읽기 편하게**: 큰 자막, 낮은 배경음, 움직임 감소.
- **조용히**: 전체 음소거, 자막 켬, 움직임 감소.
- 자막 표시·크기, 언어, 배경음·효과음 음량, 움직임을 각각 조절할 수 있다.
- 설정은 브라우저에 자동 저장한다. 저장이 차단되면 현재 관람에만 적용한다.
- JSON 내보내기/가져오기로 다른 브라우저에서도 같은 설정을 사용할 수 있다. 8KB 제한이며 올바르지 않은 파일은 기존 설정을 바꾸지 않는다.
- 초기화와 프리셋은 현재 언어를 유지한다. 설정 파일을 가져오면 파일의 언어도 적용한다.
- 설정 창을 열거나 다른 탭으로 이동하면 재생과 배경음이 멈추고, 돌아오면 이어진다.

## 검증 자동화

```sh
pnpm run check          # 설정 데이터 테스트 → 그래프·테마·에셋 검증 → 빌드 → 크기 예산
pnpm exec playwright install chromium   # 브라우저 최초 설치
pnpm run test:e2e       # 데스크톱 + 390×844 모바일 에뮬레이션
pnpm run check:all      # 위 검사 전체
```

`pnpm run build`에도 그래프·테마·에셋 및 크기 예산 검사를 포함한다. 누락 에셋이나 예산 초과가 있으면 명령이 실패한다. `available:false` 우산 에셋은 요구하지 않는다. 현재 에셋 검사는 로컬 public 경로를 대상으로 한다. 네트워크 지연·첫 인터랙션 성능·암전 여부는 크기 검사만으로 보장하지 않는다.

저장소의 GitHub Actions 설정은 관련 파일의 push/PR 때 `check:all`을 실행한다. 로컬에서 추가한 워크플로이며 원격 실행 결과는 별도 확인한다.

## 제작 설정

작품 내용은 `public/story.json`, 디자인은 `public/theme.json`에서 관리한다. 관람 설정은 원본 파일을 수정하지 않는다. 새 `settings.desktop` / `settings.mobile` 토큰으로 패널 크기·간격·글자 크기를 변경할 수 있다. 원본 제작용 `../seed/theme.json`에도 동일한 변경을 반영한다.

다음 제작 도구 확장은 텍스트·테마의 실시간 미리보기, 검증된 JSON 내보내기, 핫스팟 좌표 편집 순서로 진행할 수 있다. 현재 구현 범위는 관람 설정이며 콘텐츠 관리자·저장 서버는 포함하지 않는다.
