# 관람 설정·자동 검증 확장 QA

검수일: 2026-09-12. 대상: `projects/dawn-store/app`.

## 변경 범위

- 관람 프리셋, 세부 설정, 버전이 있는 자동 저장, 기존 언어·음소거 이전.
- 검증된 설정 파일 가져오기/내보내기와 저장 차단 시 세션 내 사용.
- 설정 대화상자·탭 비활성화 시 재생/오디오 일시정지, 움직임 감소.
- 완료된 스틸 컷에서 챕터를 다시 선택하면 재생이 재시작되도록 수정.
- 앱 초기화의 resize 이벤트 정리와 이전 미디어 레이어 정리 수정.
- 빌드에 그래프·테마·에셋·크기 예산 검사 연결, CI 워크플로 추가.

## 검증

- 설정 데이터 단위 테스트: 5개 통과 (기존 설정 이전, 손상·차단 저장소, 입출력, 잘못된 스키마/용량).
- 그래프: 8개 노드 검사, 의도된 미완성 우산 경고 1개.
- 에셋: 참조된 로컬 파일 10개 및 테마 스키마 검사 통과.
- `npm run check:all`: 설정 단위 테스트 5개, 프로덕션 빌드, 브라우저 검사 10개 통과.
- 이후 오디오 검사 2개 추가 및 최초 일시정지 검사의 셀렉터 강화 후 `npx tsc -b`와 관련 브라우저 검사 4개 재실행 통과. 최종 브라우저 스위트는 12개이며 데스크톱·모바일 각 6개다.
- 검사 내용: 프리셋/초점 제한·복귀, 저장 유지/언어 전환, 설정 파일 입출력·잘못된 파일 차단, 저장 차단 대응, 기기 움직임 설정, 완료 후 챕터 재생, 대화상자/visibilitychange 일시정지·재개, 실제 Audio 음량/음소거/재개.
- 모든 실행에서 앱 콘솔 오류·페이지 오류 0, 가로 overflow 없음. 1440×810 및 390×844 화면 캡처를 직접 확인했다.
- 크기 예산: 전체 JS gzip 90,486B / 153,600B, CSS gzip 3,425B / 20,480B, 이미지 합계 827,184B / 3,145,728B, 최대 이미지 150,790B / 409,600B, 폰트 0개 / 6개. 모두 통과.

## 검토 및 한계

React 검토: 버전이 있는 저장소 스키마, 지연 초기화, 상태 함수 업데이트, 이벤트 정리, native dialog 및 Tab/Shift+Tab 제한, 초점 복귀, 폼 라벨 확인. 런타임 의존성 추가 없음. Playwright는 개발 의존성만 추가.

GitHub Actions는 로컬 파일을 추가한 상태이며 원격 실행은 수행하지 않았다. 이번 검수는 관람 설정과 연결된 재생 흐름의 회귀 검증이다. 원래 작품 전체 수용 기준의 재인증이나 실제 4G 첫 인터랙션/무암전 측정은 포함하지 않는다. 모바일 검사는 Chromium 기기 에뮬레이션이며 실제 iOS Safari 검증은 아니다.
