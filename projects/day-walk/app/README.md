# Day Walk

하루를 아침·오후·저녁 세 구간으로 나누는 산책 일정표입니다.

- 실행: `pnpm --filter day-walk dev`
- 전체 검증: `pnpm --filter day-walk check:all`
- 단위 테스트: `pnpm --filter day-walk test`
- 타입 검사·빌드·예산: `pnpm --filter day-walk build`
- 데스크톱·모바일 동작: `pnpm --filter day-walk test:e2e`

## 사용법

- 아래 시간 레일과 일정 칸에 이어진 두 점선을 드래그하면 세 구간의 비율과 동네의 밤 영역이 함께 바뀝니다. 방향키는 1분, Shift+방향키는 15분입니다.
- 길가의 깃발과 두 경계 점선은 정각·30분의 ±5분 안에서 해당 시각에 자석처럼 붙습니다. 그 밖의 드래그는 1분 단위입니다. 깃발 방향키는 15분, Shift+방향키는 1시간 이동합니다.
- 하단 일정의 시각 또는 각 구간의 마감 시각을 입력하고 Enter를 누르거나 입력창 밖으로 이동하면 적용됩니다. `14:23`이나 `1423`처럼 입력할 수 있고, 직접 입력에는 자석 보정을 적용하지 않습니다. Esc는 취소하며 허용 범위 밖의 값은 오류를 표시하고 기존 시각을 유지합니다.
- 동네 빈 공간이나 시간 레일을 누르면 그 시각에 일정을 추가합니다. 아래 칸에서는 시각 없는 할 일도 추가할 수 있습니다.
- 상단 날짜를 누르면 달력이 열립니다. 연도·월·날짜를 고르거나 오늘로 돌아갈 수 있으며 일정은 날짜별로 저장됩니다.
- 새 말풍선의 본문을 탭하면 숨겨지고 새를 누르면 복원됩니다. 숨겨도 다음 일정의 시각에 도달하면 새 안내가 나타납니다.
- 일정을 체크하면 깃발과 제목 말풍선이 무채색으로 바뀌고 제목에 취소선이 생깁니다. 체크를 풀면 복원됩니다.
- 오늘 일정을 모두 마치면 하단 일정 영역에서 새 다섯 마리가 한 바퀴 돌고 떠납니다. 효과음 설정이 켜져 있으면 지저귐을 재생합니다. 줄이기 설정에서는 정적인 완료 문구만 보입니다.

## 구현 메모와 SPEC 해석

- 2026-09-15 사용자 이미지·동작 요청이 기존 SPEC의 SVG 전용 화면, 등폭 칸, 조언 순환, 전체 화면 폭죽보다 우선합니다.
- 맑은 아침·노을 오후·밝은 저녁의 배경 3장과 캐릭터·새 WebP로 미디어 5개를 사용합니다. 2026-09-15 후속 요청에 따라 미디어 예산을 5개로 변경했습니다. 이전 주택가 원본은 `.claude/asset-history/`에 보관합니다. 외부 이미지·폰트·오디오 요청과 추가 의존성은 없습니다.
- 숨겨진 SVG 씬을 기능 대용으로 유지하던 방식을 제거하고 실제 보이는 깃발과 새를 접근 가능한 컨트롤로 연결했습니다.
- 배경에 CSS 밝기·색상 필터를 적용하지 않습니다. 아침의 맑은 하늘과 초록빛, 오후의 살구색 노을, 밝은 저녁의 세 이미지가 동일 구도로 넓게 크로스페이드되며 두 경계를 따라 이동합니다. 창문 불빛·하늘·도로 조명이 이미지에 포함되어 있고 검은 오버레이·비네트도 제거했습니다. 상단 높이는 이전의 `clamp(30rem, 62vh, 46rem)`로 복원했습니다.
- 새는 캐릭터 높이를 기준으로 머리 위에 떠 있습니다. 배경과 같은 입체 질감의 청회색·크림색 새가 두 프레임으로 날갯짓하며 천천히 오르내립니다. 완료 연출에도 같은 새를 사용하며 움직임 줄이기 설정을 따릅니다. 깃발에는 금속 깃대·마감 장식과 입체적인 천·봉제선을 추가했으며, 가까운 깃발의 제목은 높이를 달리해 배치합니다. 입력창과 말풍선은 종이색·회보라색으로 통일했습니다.
- 씬, 레일, 데스크톱 일정 칸은 `xOf` 좌표와 동일한 세 구간 너비를 사용합니다. 모바일은 가로 스크롤 없이 기존 세 탭으로 일정을 봅니다.
- 시간 확대와 촘촘한 분 눈금은 사용하지 않습니다. 아래 레일은 시간 참고 눈금과 시작·두 경계·마감의 네 시각을 보여 줍니다.
- 두 경계는 1분 정밀도이며 최소 한 시간 간격을 유지합니다. 하나를 끌 때 다른 경계는 움직이지 않습니다. 드래그 중 배경·칸 너비를 즉시 반영하고 저장은 기존 300ms 디바운스를 사용합니다.
- 점선은 씬에서 보드까지 이어지며 레일·보드 구간에서 잡습니다. 씬에 겹친 점선이 일정 깃발의 조작을 가로채지 않습니다.
- 완료와 무관하게 시각이 지난 깃발은 계속 표시합니다. 완료 시 제목 취소선·무채색·접힌 깃발을 적용합니다.
- 캐릭터는 실제 시각만 따라 30초 간격으로 이동합니다. 다른 날짜에서는 캐릭터와 새를 숨기고 선택한 날짜를 안내합니다. URL `?now=2026-09-14T10:00`으로 검증 시각을 지정할 수 있습니다.
- 말풍선의 숨김 상태는 평소 시계 갱신에도 유지합니다. 새 일정 도달을 감지할 때만 자동으로 다시 보이고, 같은 도달 안내는 중복 표시하지 않습니다. 새를 누르면 현재 안내를 복원합니다.
- 완료 연출은 보드 안에서만 재생하고 약 6.8초 뒤 제거합니다. 날짜별 1회 기록을 저장하므로 새로고침 후 반복하지 않습니다. Esc 또는 닫기로 즉시 종료할 수 있습니다.
- `move-overdue`는 현재 구간보다 앞선 구간의 미완료·시각 없는 할 일만 옮깁니다. 시각 있는 일정의 구간은 저장하지 않고 `segmentOf`로 계산합니다.
- 저녁 마감 `00:00`~`04:00`은 다음날로 해석합니다. 루틴의 오늘은 현재 선택한 논리적 날짜이며 중복 일정은 건너뜁니다.

## 최종 검증 (2026-09-15)

`pnpm --filter day-walk check:all` 통과: 단위 13개, 브라우저 58개 통과·실패 0개. 기기 전용 2개는 반대 기기에서 제외합니다. 타입 검사·프로덕션 빌드·예산 모두 통과했습니다. 실제 터치 드래그, 자석 범위 안팎의 이동, 경계와 겹친 깃발, 드래그 취소, 직접 시각 입력·취소·잘못된 값·자정 이후 입력, 경계·배경·칸 너비 연동, 날짜별 데이터, 말풍선 재표시, 완료 연출 종료와 새로고침 유지까지 검증했습니다.

상쾌한 아침·노을 오후·입체 새 적용 후 같은 전체 검증을 재실행해 모두 통과했습니다. 별도 실제 브라우저 확인에서 PC·모바일 이미지 요청 오류 없음, 새 말풍선 복원, 두 날갯짓 프레임 전환, 움직임 줄이기 시 애니메이션 정지를 확인했습니다. JS gzip 97,980B, CSS gzip 11,141B입니다.

## 배경 생성 기록

내장 `image_gen` 편집 도구로 원본 주택가의 구도를 유지한 낮·초저녁 두 버전을 생성했습니다. 최종 파일은 `public/media/day-walk-daylight-v3.webp`, `public/media/day-walk-evening-v3.webp`입니다. FFmpeg로 PNG를 WebP로 인코딩했으며 추가 색상 보정은 하지 않았습니다. 최종 프롬프트는 [.claude/plans/day-walk-relighting-prompts.md](.claude/plans/day-walk-relighting-prompts.md)에 기록했습니다.

후속 요청의 오후 노을은 `public/media/day-walk-afternoon-v4.webp`, 입체 새는 `public/media/day-walk-bird-v3.webp`입니다. 새 에셋은 실제 알파 대신 RGB로 생성되어 녹색 매트를 렌더링 시 SVG 색상 행렬로 투명하게 처리합니다. 내장 도구의 최종 프롬프트와 파일 목록은 [.claude/plans/day-walk-morning-bird-prompts.md](.claude/plans/day-walk-morning-bird-prompts.md)에 기록했습니다.
