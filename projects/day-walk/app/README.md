# Day Walk

`pnpm test`, `pnpm exec tsc -b`, `pnpm exec vite build`로 검증합니다.

## 구현 메모

- `clampBounds`는 각 경계를 15분 단위로 반올림한 뒤, 앞 경계부터 가장 가까운 유효 범위로 제한합니다.
- 단계 4에서는 씬·타임라인을 다음 단계의 SVG/상호작용 구현 전까지 높이만 확보하는 플레이스홀더로 두었습니다.
- `move-overdue`는 현재 구간보다 앞선 구간의 미완료·시각 없는 할 일만 옮깁니다.
- 타임라인의 경계 라벨은 좌표계 양 끝과 두 마감 시각의 네 개만 표시하며, 빈 영역 키보드 Enter는 하루 시작 시각에 빠른 추가를 엽니다.
- 단계 6의 과거·미래 날짜 안내는 선택 날짜를 한국어 월·일 표기로 표시하며, 루틴 대화상자는 단계 7 범위라 조언의 열기 콜백만 연결했습니다.
- 단계 7의 저녁 마감 `00:00`~`04:00` 입력은 다음날(`+1`)으로 해석하며, 루틴의 “오늘”은 현재 선택한 논리적 날짜를 뜻합니다.
- 씬의 SVG 좌표 폭은 `ResizeObserver`로 측정한 컨테이너 종횡비에 맞춰 계산하고, 모든 씬 x 좌표는 그 폭에 비례시켰습니다.
- 제목 해시는 `domain/visual.ts`의 순수 함수로 계산해, 일정 집의 토큰 벽색 5종과 70~90 높이를 결정합니다.
- 모바일 말풍선은 씬의 상단 안전 여백 안에 고정·가로 클램프합니다. 좁은 공간에서는 새와 반대쪽 가장자리 쪽으로 꼬리 기준점을 옮깁니다.
- 모바일에서 타임라인 빠른 추가를 완료하면 생성 시각을 `segmentOf`로 계산해 해당 구간 탭을 선택합니다. 깃발 클릭·드래그도 같은 `timeline-segment` 이벤트를 사용합니다.
- 축하 캔버스는 2.5초 후 DOM에서 제거하지만, 축하 문구 오버레이는 사용자가 닫거나 Esc를 누를 때까지 유지합니다.
- 씬의 접근성 라벨은 현재 시각, 계산된 구간, 남은 일 수를 포함합니다.
- 루틴을 오늘에 불러오면 결과 토스트를 띄운 뒤 루틴 대화상자를 닫고, 닫힌 대화상자는 연 요소로 초점을 되돌립니다.
- overdue 조언은 미완료가 지난 한 구간에만 있으면 해당 구간명을, 둘 이상의 지난 구간에 걸치면 구간명 없는 합산 문구를 사용합니다.
