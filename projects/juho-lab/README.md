# JUHO LAB

이주호의 바이브 코딩 포트폴리오. Three.js 기반 프로젝트 전시 공간과 2D 목록, 분야별 필터, 검색, 프로젝트 소개·바로가기를 제공한다.

## 로컬 실행

```powershell
py -3 -m http.server 4182 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:4182/ 에서 연다. 빌드가 필요 없는 정적 HTML/CSS/JavaScript다. `dist`는 생성 파일이 아닌 원본 소스이므로 삭제하지 않는다.

## 프로젝트 추가 및 수정

- `dist/projects.js`: 프로젝트 목록·소개·링크·이미지·분야·기술 태그와 작성자 소개. `url`과 `linkLabel`을 수정하면 공개 서비스 바로가기로 바꿀 수 있다.
- `dist/tokens.css`: 배경색·포인트색·글꼴·페이지 여백.
- `dist/scene.js`: 3D 패널·카메라·입력·렌더링. 기기 픽셀 비율은 1.7로 제한한다.
- `dist/assets`: 포트폴리오 이미지, Three.js 0.180.0 정적 모듈과 MIT 라이선스.

선택한 프로젝트는 URL 해시에 반영된다. 3D 공간은 드래그·클릭·방향키로 탐색하며 Home/시점 초기화로 돌아간다. 움직임 감소와 목록 보기를 제공하고 WebGL을 사용할 수 없으면 목록으로 전환한다. 비활성 탭과 목록 보기에서는 3D 렌더 루프를 멈춘다.

## 콘텐츠 근거

ChemiForge, 사수, 숏폼 자동화, MARKET FRONT, 종말의 탑의 로컬 README와 새벽 세 시의 SPEC를 사용했다. 모든 링크는 확인된 Git origin의 GitHub 저장소다. 실제 서비스 공개 URL은 확인되지 않아 임의로 작성하지 않았다. `sasu.webp`는 기존 제출용 썸네일, `dawn.webp`는 기존 작품 에셋이다. 배포되는 파일에는 로컬 경로·환경변수·키·고객 정보가 없다.

## 검증

`node scripts/validate.mjs`는 모듈 구문, 프로젝트 데이터, 로컬 에셋과 import 경로를 검증한다. WebMCP가 제공되는 브라우저에서 프로젝트 검색/선택 도구를 등록하며, 지원되지 않거나 등록이 실패하면 일반 화면은 정상 동작한다.

이번 작업에서는 Sites 스킬의 브라우저 검수 범위에 따라 사용자용 미리보기만 열고 별도 클릭·스크린샷 QA를 수행하지 않았다. WebMCP 실환경 호출 검증도 미수행이며 지원되지 않는 환경에 대한 기능 탐지는 포함한다.

Sites 배포는 전용 Git 체크아웃에서 이 폴더의 동일한 검증 소스를 게시한다. 기존 모노레포의 다른 프로젝트는 게시하지 않는다.
