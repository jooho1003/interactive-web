# JUHO LAB

이주호의 바이브 코딩 포트폴리오. 야간 아틀리에 배경과 Three.js 원근형 작품 전시, 2D 목록, 분야별 필터, 검색, 프로젝트 소개·바로가기를 제공한다.

## 로컬 실행

```powershell
py -3 -m http.server 4182 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:4182/ 에서 연다. 빌드가 필요 없는 정적 HTML/CSS/JavaScript다. `dist`는 생성 파일이 아닌 원본 소스이므로 삭제하지 않는다.

## 프로젝트 추가 및 수정

- `dist/projects.js`: 프로젝트 목록·소개·링크·이미지·분야·기술 태그와 작성자 소개. `url`과 `linkLabel`을 수정하면 공개 서비스 바로가기로 바꿀 수 있다.
- `dist/style.css`: 전시실 구성, 색상, 반응형 레이아웃. `dist/tokens.css`: 공통 글꼴.
- `dist/scene.js`: 3D 패널·카메라·입력·렌더링. 기기 픽셀 비율은 1.7로 제한한다.
- `dist/assets`: 포트폴리오 이미지, Three.js 0.180.0 정적 모듈과 MIT 라이선스.

선택한 프로젝트는 URL 해시에 반영된다. 3D 공간은 드래그·클릭·방향키로 탐색하며 Home/시점 초기화로 돌아간다. 움직임 감소와 목록 보기를 제공하고 WebGL을 사용할 수 없으면 목록으로 전환한다. 비활성 탭과 목록 보기에서는 3D 렌더 루프를 멈춘다.

## 콘텐츠 근거

ChemiForge, 사수, 숏폼 자동화, MARKET FRONT, 종말의 탑의 로컬 README와 새벽 세 시의 SPEC를 사용했다. 모든 링크는 확인된 Git origin의 GitHub 저장소다. 실제 서비스 공개 URL은 확인되지 않아 임의로 작성하지 않았다. `sasu.webp`는 기존 제출용 썸네일, `dawn.webp`는 기존 작품 에셋이다. 배포되는 파일에는 로컬 경로·환경변수·키·고객 정보가 없다.

## 검증

`node scripts/validate.mjs`는 모듈 구문, 프로젝트 데이터, 로컬 에셋과 import 경로를 검증한다. WebMCP가 제공되는 브라우저에서 프로젝트 검색/선택 도구를 등록하며, 지원되지 않거나 등록이 실패하면 일반 화면은 정상 동작한다.

이번 작업에서는 Sites 스킬의 브라우저 검수 범위에 따라 사용자용 미리보기만 열고 별도 클릭·스크린샷 QA를 수행하지 않았다. WebMCP 실환경 호출 검증도 미수행이며 지원되지 않는 환경에 대한 기능 탐지는 포함한다.

Sites 배포는 전용 Git 체크아웃에서 이 폴더의 동일한 검증 소스를 게시한다. 기존 모노레포의 다른 프로젝트는 게시하지 않는다.

## 2026-09-12 시각 개편

전용 야간 건축 배경(atelier.webp), 큰 작품 중심의 3D 캐러셀, 측면 작품 원근감, 바닥 반사, 포인터 시차를 적용했다. 새벽 세 시가 기본 작품이다. 전환이 끝나면 렌더 루프가 쉬고, 움직임 감소 시 전환을 즉시 완료한다. 상세 정보는 작업 노트로 펼친다. 전체 목록은 이미지 카드로 바꾸고 검색/분야 필터를 유지했다.

chemiforge.webp는 해당 프로젝트의 evidence-hero.png, spire.webp는 해당 프로젝트의 steam-landscape-escape-en-keyart-16x9-v5.png에서 웹용으로 압축한 기존 자산이다. atelier.webp만 이번에 생성한 원본 배경이다. 새 프로젝트의 GitHub 링크를 실제 서비스 링크로 임의 대체하지 않았다.

검증 범위: 정적 경로·JS 구문·CSS 이미지 경로·고유 ID, 0~6개 필터 결과의 캐러셀 순환과 선택 위치. 브라우저 클릭·스크린샷·모바일 실기기 QA는 별도로 수행하지 않았다.

## 작품 진입 (2026-09-12)

작품 패널과 이름, 전체 컬렉션과 2D 목록 카드는 목적지로 이동하는 링크다. `projects.js`의 `liveUrl`이 있으면 서비스/체험으로 바로 이동하며, 없으면 `project.html?id=...` 개별 작업 페이지로 들어간다. 기존 `url`은 소스 저장소 링크로 유지한다. SASU는 기존 배포 기록과 HTTP 200으로 확인한 주소를 연결했다. ChemiForge의 기록된 배포 주소는 404여서 사용하지 않았다.

새벽 세 시는 원본 앱의 `npm run build`를 통과한 후 `node scripts/include-dawn.mjs`로 포함한 정적 스냅샷이다. 자산 경로를 하위 폴더에 맞추고, 돌아가기 바가 있는 별도 프레임에서 원본 작품을 실행한다. 원본 앱 소스는 수정하지 않는다. 재포함하려면 원본 앱을 먼저 빌드한다. 원본 스토리의 비활성 umbrella 노드와 경고는 그대로 유지한다.

드래그·가로 휠·방향키·번호 버튼은 작품을 넘기고, 클릭과 Enter는 작품으로 입장한다. 세션 저장소로 선택/검색/분야/보기 방식/스크롤을 복원한다. 뒤로 가기도 지원하며 저장소 사용 불가 환경에서도 탐색은 동작한다.

이번 변경은 Chromium에서 실제 클릭, 개별 페이지 진입, 필터를 적용한 복귀, 드래그와 진입 분리, 키보드로 새벽 세 시 실행, 모바일 390px 목록/상세 이동, 잘못된 ID, 런타임 오류를 확인했다. 앞 절의 브라우저 QA 미수행 기록은 이전 버전에 해당한다. 참조: https://dinotaeng.com/project/ 의 수평 공간 탐색 및 진입/복귀 흐름. 참조 사이트 자산과 코드는 복사하지 않았다.
