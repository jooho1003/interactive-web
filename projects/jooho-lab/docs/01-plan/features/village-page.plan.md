# 작업 동네 별도 페이지 복원 · 2026-10-03

## Executive Summary
| 관점 | 내용 |
|---|---|
| 문제 | 처음 만든 작업 동네가 현재 전시관에서 접근되지 않는다. |
| 해결 | 기존 파노라마·카메라·입장 동작을 village.html에서 재사용한다. |
| 효과 | 전시관과 동네를 오가며 같은 작품의 실제 운영 주소를 방문한다. |
| 가치 | 승인된 이전 시각 자산을 버리지 않고 다른 관람 방식으로 활용한다. |

## Context Anchor
WHY: 초기 디자인 보존. WHO: 포트폴리오 방문자/소유자. RISK: 여섯 집에 일곱 작품을 붙여 마지막 작품이 빠짐, 설정 충돌. SUCCESS: 7작품 탐색/운영 링크/복귀, 모바일·키보드·동작 줄이기·전체 파라미터 probe 통과. SCOPE: 별도 페이지/기존 코드 재사용/양방향 링크/페이지별 레이어 설정.

## 범위·요구사항
사용자가 제공한 처음 디자인을 독립 페이지로 복원한다. 메인 전시관의 입장·건물은 유지한다. 작품 목록/공유 편집/방문 링크는 현재 projects.js를 공유한다. 여섯 집은 현재 작품 01~06에 대응하고 하루 산책은 같은 파노라마 앞 산책길의 일곱 번째 정류장으로 연결한다. 새로운 그림/모델은 만들지 않는다. 기본 선택은 사진처럼 SASU이며 두 페이지의 선택·뷰 복원은 분리한다.

## 레이어 계약
동네 전용 manifest/저장 키를 두고 기존 설정 패널을 재사용한다. stage(파노라마·카메라), intro(인사), labels(건물/산책길 링크), character(보행자), ambient(창 조명), entry(입장 피드백), controls(번호·화살표·안내), shell(메뉴·목록)을 선언한다. 모두 visible/opacity, 관련 크기·색·문구·이미지·모션 파라미터를 둔다. 파노라마와 집 핫스팟 좌표는 원본 그림에 맞춘 구조 좌표로 fixed에 기록한다. 콘텐츠 목록은 공유 registry/편집기가 담당한다. lint 오류 0 및 전 파라미터 실제 브라우저 probe가 완료 조건이다.

## 실행·검증
1. 페이지/링크/공유 런타임 분기 → 전시관 회귀 검수.
2. 기존 동네·7정류장·독립 레이어 → 입력/취소/초기화/설정 저장 및 실패/모바일 검수.
3. check/build·자료 보관함 → QA 기록과 미검수 범위 구분.
