# 복원한 초기 작업 동네

`../../public/village.html`의 검수 자료. 사용자 참고 이미지: `docs/참고/2026-10-03 00 59 00_005.png`.

- `desktop.png`, `mobile.png`, `short-mobile.png`: 원래 SASU 중심 구도.
- `*-day-walk.png`: 일곱 번째 산책길 정류장. 원본에 새로운 집을 합성하지 않는다.
- `*-qa.json`: 동네 62개 동작/경계 검사와 42개 파라미터 probe.
- `settings-and-navigation-qa.json`: 실제 설정/저장 실패/내보내기/운영 Day Walk 진입.
- `aside-desktop-first-qa.json`: Aside에서 background 탭으로 바뀌어 중단된 검사.
- `desktop-layer-first-qa.json`: 진행률 0의 투명 입장 배경색을 probe하던 실패 후보.
- `assets.json`: 원본 재사용 에셋의 크기와 SHA256. 새 이미지 생성 없음.

검수 정본: [QA-village.md](../../QA-village.md). 원본 프롬프트 이력: [카드 01/02](../../../../prompts/jooho-lab.md#01--마을-파노라마-project-village).
