# 운영 작품 전시 이미지 · 2026-10-03

운영 사이트 7개를 Aside에서 실제로 열어 확인한 뒤 만든 전시 대표 이미지다. localhost는 제작 참조가 아니라 바뀐 LAB의 표시·동작 검수에만 사용했다.

- `sources.json`: 운영 주소, 재사용 원본 출처, 최종 크기·용량·인코딩.
- `<id>.png`: 운영 사이트의 참조 캡처. 최종 전시 이미지는 UI 전체 캡처를 쓰지 않는다.
- `prompts.json`: built-in image_gen에 실제 전달한 프롬프트 6개와 참조 경로.
- `<id>-art.png`: 새 생성 원본 6개. 세로 4:5, 1122×1402. 모델명·시드는 tool에서 노출되지 않았다.
- `chemiforge-hero.webp`: 운영 hero 다운로드 참조. 가로 원본 직접 사용 후보는 액자에서 작아 보여 세로 생성본으로 교체. 실제 형식은 Pillow로 판독, 확장자는 다운로드 보관명이다.
- `instatoon-cover.webp`: 공개 한술툰 1편 표지 원작 다운로드. 기존 만화 글자를 보존한다.
- 최종 `../../public/assets/exhibit-*.webp`: 7개, 총 1,354,226B. 무크롭·비율 유지, 주제와 이름표를 기존 전시 레이어로 분리했다.

사용자는 운영 없는 숏폼 자동화/Market Front 대신 음식 블로그/한술툰을 전시하도록 정정했다. 이전 이미지와 prompts 카드 07은 역사 자료로 보존했다. 모든 방문 링크는 `sources.json`의 실제 운영 주소다. 개인 설정에서 지정한 이미지·링크는 기존 우선순위를 유지한다.

생성물은 사이트를 나타내는 키 비주얼이다. 블로그의 초밥 정물은 특정 방문을 증명하는 실제 사진이 아니다. Day Walk는 운영 화면의 걷는 여성/새와 아침·오후·밤의 동네를, 새벽 세 시는 편의점과 빗물·커피를, 종말의 탑은 실제 타이틀 화면의 붉은 균열 탑을 참조했다. SASU는 대화와 근거가 하나의 결정으로 모이는 정물로 표현한다.
