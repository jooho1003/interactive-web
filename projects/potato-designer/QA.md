관리자 게시 검수는 `node scripts/studio-qa-server.mjs`로 만든 **임시 복사본(4178)** 에서 수행했다. 실제 작업 서버(4176)의 게시값은 기본 상태를 유지했다. QA 함수는 별도 Playwright Page에 전달하며, 다른 포트에서는 실행을 거부한다. 레이어 probe는 전용 검수 페이지에서 `import('/vendor/layer-kit/probe.js')`의 `probe(layerHost)`로 실행한다.

발견·수정: 루트 장면 속성과 기존 버튼 선택자의 충돌, 패널 공통 이동/배율/불투명도가 개별 패널에 덮이는 문제, 애니메이션에 가려진 중복 그림자 회전값, 0초 기본 프레임의 캐릭터 숨김, 사각형 크기만 비교하던 선택기가 앞쪽 이미지를 선택하지 못하는 문제, iframe/부모 사이 객체의 realm 차이, 초안 충돌 시 수정 내용 보존. 모션 시점 확인은 CSS 애니메이션을 사용하며 임의 키프레임 편집기는 포함하지 않는다.

로컬 단일 사용자 제작 도구의 검수다. 실제 iOS/Android, Safari/Firefox, 스크린 리더, 원격 다중 사용자 인증·배포는 이번 검수 범위가 아니다. 다른 세 앱의 레이어 이관도 완료했다고 주장하지 않는다.

## 수정·개발 내용

- 캐릭터의 그리드 최소 크기로 인해 헤더·푸터까지 넘치던 현상 수정: 부모 높이를 따르게 하고 무대 내부로 표시 범위를 제한했습니다.
- 모바일 분야 버튼을 캐릭터 아래에 배치하고, 320px 작업 패널의 카드 너비와 글자 크기를 수정했습니다.
- 모션을 멈춰도 현재 자세와 분야를 유지합니다. 작업을 선택해도 수동 정지를 해제하지 않습니다.
- 동작 줄이기 설정에 맞춰 두 재생 버튼을 비활성화하고 상태를 표시합니다. 설정을 되돌려도 사용자의 수동 정지 선택은 유지합니다.
- 모달을 열거나 문서가 숨겨지면 배경 애니메이션을 정지합니다. 문서 숨김 처리는 코드 검토했으며 실제 탭 전환 자동 검사는 포함하지 않았습니다.
- 메모 내용·분야를 브라우저 저장소에 자동 저장·복구합니다. 초안 삭제, 저장소 차단 안내, 한글·이모지를 포함한 텍스트 다운로드를 지원합니다.
