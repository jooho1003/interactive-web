# 참고 경험 재검토와 설정

- 문제: 이전 화면은 소개문/금속 프레임 카드 중심. 실제 폰트 로딩 부재. 포트폴리오 설정 진입점 부재.
- 참고: Dinotaeng project의 수평 공간, 대상별 오브젝트, 중앙 포커스, 클릭 진입과 복귀. 참조 자산 복제하지 않음.
- 구현: 독립 6개 건물의 2.5D 파노라마, 짧은 문구, 풀 화면 탐색, 실제 Pretendard 파일, 명시적인 설정 모달(글자크기/움직임/공간확대/기본보기/개인 링크), 안전한 로컬 저장.
- 설정은 이 브라우저 개인화이며 전 방문자 공통 변경으로 오인시키지 않음.
- 기본 기능: 6작품/검색/분류/진입/복귀/키보드/모바일/실제 체험 유지.
- 검증: 참고 화면과 결과 직접 점검, 폰트 로드/설정 저장과 복원/링크 검증/모바일·PC/동작 테스트, 기존 private Site 게시.
- G1 PASS; G2 설계와 판단 main PASS; G3 main 유지 PASS; G4 자산 전용 1에이전트 PASS; G5 기존 권한 유지 PASS.
