# 작품 진입과 공간 탐색

사용자 지정 참고: https://dinotaeng.com/project/ — 가운데 정렬된 수평 탐색, 드래그/키보드/가로 휠, 페이지 표시, 작품 클릭 상세 진입, 돌아올 때 위치 복원.

- 작품 클릭은 진입. 이동 제어는 드래그/방향키/페이지 버튼으로 구분.
- 확인된 SASU 실제 URL 연결. 새벽 세 시 검증 빌드를 동일 비공개 포트폴리오 하위에 포함. 나머지는 독립 상세 페이지와 코드 링크.
- 탐색 상태는 세션 내 복원. 모든 작품의 상세 URL 직접 접근 및 잘못된 ID 처리.
- 기존 Site ID와 공개 범위 유지. 참조 사이트의 이미지/소스는 복제하지 않음.
- main 설계/구현/최종검토. G1 완전성 PASS, G2 판단 main PASS, G3 현재 세션 PASS, G4 위임 없음 PASS, G5 기존 권한 유지 PASS.
- 검증: 정적 링크/경로, 클릭과 드래그 분리, 상세 페이지/목록 복원, 포함한 체험 자산 경로.
