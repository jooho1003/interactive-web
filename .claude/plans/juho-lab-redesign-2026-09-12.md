# JUHO LAB 공간 품질 개선

사용자 요청: 새벽 세 시 수준의 몰입감과 완성도. 기존 포트폴리오 재설계.

- 방향: 야간 개인 전시실, 실제 재질의 건축 배경, 대형 3D 작품과 선택 전환, 따뜻한 타이포그래피.
- 보존: 6개 실제 프로젝트, 검색/분야, 목록 대체 보기, 키보드, 움직임 감소, WebMCP, 기존 비공개 Site.
- 구현: main이 레이아웃/Three.js/접근성/최종 리뷰 수행. Sites 스킬 요구에 따라 자산 전용 에이전트 하나가 배경만 생성.
- 검증: 정적 파일 및 JS 검사, 순환 배치/필터 계산 검증, HTTP 자산 확인. 브라우저 QA는 명시 요청이 없어 Sites 지침에 따라 제외.
- G1 완전성 PASS; G2 설계·최종 판단 main PASS; G3 현재 세션 유지 PASS; G4 독립 자산 작업 1개 한정 PASS; G5 기존 데이터·공개범위 유지 PASS.
- 순서: 자산 → 레이아웃/상호작용 → 검증 → 기존 사이트에 반영.
