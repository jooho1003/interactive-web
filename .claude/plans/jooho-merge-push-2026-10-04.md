# 로컬 작업 커밋·원격 main 통합·푸시

사용자 승인: "커밋 머지 푸시 해줘". 기존 local main은 origin/main보다 39개 뒤에 있다. 원격의 최신 LAB 전시관·동네·선비 작품·레퍼런스 보관소를 보존하면서 이번 Potato 등록/동네 건물/레이어 변경과 로컬 제작 문서를 통합한다.

참고: 허브 README·QA, docs/00·10, 기존 머지 기록, origin/main diff와 manifest/runtime. 이전 juho-lab 빌드 잔여물과 sh.exe.stackdump는 작업 산출물이 아니므로 커밋에서 제외하되 파일은 보존한다. 외부 레퍼런스 신규 설계 없음(해당 없음).

순서: feature 브랜치에서 기존 문서와 기능을 커밋 → 원격 main 머지·충돌 통합 → 생성물 재빌드·검사·브라우저 검수 → main에 머지 → fast-forward 가능한 일반 push. 강제 푸시하지 않는다.

레이어 계약: 원격 전시관/동네 stage 설정을 보존하며 새 house/extension 매니페스트는 별도 이름으로 분리해 같은 파일을 덮지 않는다. 원격 추가 작품의 ID를 보존하고 작품 번호 충돌을 해소한다. lint/probe와 새 통합 검수를 기록한다. 원래 이미지 기반 집 6채는 구조 고정값이다.

G1~G5 PASS. 최종 리뷰/충돌 판단은 powerful·primary 하드 오버라이드. 원격에 쓰는 작업은 사용자 명시 승인에 포함된다. 실제 배포는 요청 범위에 추가하지 않는다.

통합 구현/검수 완료: 별도 집 매니페스트, 07 하루 산책/08 POTATO/09 선비, 두 호스트의 숨김 소유권/장면 root, 공통·개별 라벨 합성. 전체 check/build 및 전시관57·동네42·Potato619 파라미터 검수 PASS. 최종 브라우저9목적지/99파라미터 재검수 후 main 병합·일반 push를 실행한다. 운영 배포는 별도 미검수.
