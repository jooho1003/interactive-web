# Potato Designer 기능 확장·학습 설계

요청: 기능 확장 및 인터랙티브 작업마다 학습 설계를 남기는 지속 규칙.

구현: 3개 스터디의 검색/분야/관심 필터, 상세 기획·산출물, 브라우저 관심 저장, 참고 작업을 초안과 다운로드에 연결. 기존 메모 본문을 덮어쓰지 않는다. 데이터는 정적이며 실제 고객 사례로 표현하지 않는다.

학습 의미 확정: 사용자는 에이전트가 기존 레퍼런스·원칙·구현 방식을 읽고 다음 개발에 적용하라는 뜻으로 설명했다. 사용자 교육 기능은 만들지 않는다. 루트 AGENTS.md와 docs/10에 읽기 순서와 검증된 교훈을 기록한다.

이번 참고: 01 §1·§5 (복제→확장/레퍼런스 복습), 04 §0·§4 (핵심 조작의 단계적 검증), 06 §4·§5 (비주얼과 실용 기능 결합). 적용: 정적 작품 데이터 분리, 탐색→상세→메모의 기능 흐름, 기존 검수 재사용. 보류: 관리자·3D 엔진·공용 패키지는 현재 정적 스터디 범위와 두 번째 소비자 부재로 추가하지 않는다.

G1 PASS (JSON 필드 완비), G2 PASS (설계·최종 검토 직접), G3 PASS (frontend/review), G4 PASS (설계와 최종 검토의 powerful 예외 근거 기록), G5 PASS (로컬 수정, 배포 없음). 현재 메인 모델을 유지하며 추가 에이전트 없음.

완료: 작업 데이터 분리, 검색·필터·상세·관심 저장·참고 작업 메모 연결 구현. 학습 의미에 맞춰 루트 AGENTS.md와 docs/10에 개발 참고 규칙·근거·검수 교훈 저장. 데이터 테스트 4개, 기존 브라우저 검사 52개와 신규 40개 통과. 데스크톱 목록·모바일 상세 육안 검수 완료. 배포 없음.
