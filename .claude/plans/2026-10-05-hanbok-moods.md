# 선비 사이트 — 시·서·화 분야 전환 설계 (2026-10-05)

`projects/hanbok-hero`를 Potato처럼 "분야를 고르면 첫 화면 분위기가 바뀌는" 사이트로 넓힌다. 이번 단계는 분야 전환만 만든다. Work·About·Contact 시트는 다음 단계다.

## 0. 요청과 합의 (사용자 답, 2026-10-05)

- 요청: "potato 만든것 처럼 선비도 사이트 개선이 필요해." 대상은 JOOHO 마을이 아니라 선비 사이트 자체.
- 주인공은 **가상의 선비**다. 이름은 **소운(小雲) 윤하담**(관리자에서 바꿀 수 있는 글자 값). "이주호"는 작은 제작 표시로만 남긴다.
- 분야 3개는 **시(詩)·서(書)·화(畫)**. 화면에 한글과 한자를 같이 적는다.
- 분위기 전환은 **안 B**다. 배경 그림을 분야별로 3장 **모두 새로** 만든다(지금 경회루 그림도 교체). 그림체는 선비 캐릭터·참조 화풍과 같은 **회화풍 콘셉트 아트**.
- 이번에 만들지 않는 Work·About·Contact 메뉴와 "작품 보기" 버튼은 레이어 값으로 숨기고, 다음 단계에서 시트와 함께 켠다.
- Work의 내용은 다음 단계에서 "선비 세계관 콘텐츠"로 채운다(이번 범위 밖, 결정만 기록).

## 4. 화면과 동작

| 입력 | 바뀌는 상태 | 보이는 피드백 | 되돌리기 |
|---|---|---|---|
| 분야 버튼 클릭·탭 | 장면 `si`/`seo`/`hwa`, `<html data-layer-scene>` | 배경이 이전 그림 위로 `moodFade` 동안 겹쳐 바뀌고, 큰 한자·부제·강조색·선비 위치가 함께 바뀜. 고른 버튼 강조(`aria-pressed=true`) | 다른 분야 버튼 |
| Tab·Enter·Space | 같음 | 같음 + 포커스 테두리 | 같음 |
| 포인터 이동 | 시선(기존) | 분야 버튼 쪽으로 옮기면 선비가 그쪽을 봄 | 기존 규칙 |
| 다시 방문 | 저장된 분야로 시작 | — | 다른 분야를 고르면 덮어씀 |
| 동작 줄이기 | 전환 시간 0 | 즉시 바뀜 | OS 설정 |

분야별 시작값(배경 확정 뒤 화면을 보고 관리자에서 다듬는다):

| | 시 `si` | 서 `seo` | 화 `hwa` |
|---|---|---|---|
| 배경 | 향원정 보름달 밤 | 한옥 사랑채·서원 마루, 창호지 문의 등불 | 비 갠 뒤 운무 낀 인왕산 바위, 새벽 |
| 큰 한자 | 詩 | 書 | 畫 |
| 부제 | 달을 읊고 바람을 적는 선비 | 먹을 갈아 마음을 쓰는 선비 | 산과 물을 화폭에 옮기는 선비 |
| 강조색 | 달빛 은청 `#b9c7d6` | 낙관 주홍 `#c8553d` | 석채 녹청 `#6f9a8d` |

마크업: 분야 버튼은 `role="group"`(이름은 `moods.label`, 기본 "분야") 안의 `<button data-scene>` 3개. 한자 `<span>`과 큰 한자 레이어는 `aria-hidden="true"`라 스크린리더는 "시·서·화"로 읽는다.

## 5. 레이어 계약

장면: `hero` 1개 → `si`(시)·`seo`(서)·`hwa`(화), `initialScene: "si"`. 구간 wide·tablet·mobile은 그대로. 지금 `layers.values.json`의 `scenes`가 비어 있어 옮길 저장값이 없다.

| 레이어 | 상태 | 파라미터 (★ 장면 `set`으로 분야마다 다름) |
|---|---|---|
| `global` | 고침 | 기존 5개 + `accent`★(color), `moodFade`(ms, 기본 600) |
| `paper` | 고침 | `image`★, 기존 `color`·`vignette`·`vignetteInner` |
| `glyph` | 새로 | `visible`·`opacity`(기본 0.08), `text`★, `font`(select: 글꼴 후보는 index.html Google Fonts와 짝), `size`(vh), `x`·`y`(%), `color` |
| `title` | 고침 | `name` 기본값 "소운 윤하담", `tagline`★ |
| `character` | 장면 값만 | `x`·`y`·`size`를 장면별로 덮을 수 있다(새 파라미터 없음) |
| `moods` | 새로 | `visible`·`opacity`, `label`(그룹 이름), `ko1..3`(시·서·화), `hanja1..3`(詩·書·畫), `font`, `size`, `color`, `gap`, `x`·`y`, `direction`(select: 세로/가로, 모바일 기본 가로) |
| `credit` | 새로 | `visible`·`opacity`, `text`(기본 "제작 이주호"), `color`, `size`, `x`·`y` |
| `nav`·`cta` | 값만 | `layers.values.json` base에서 `visible: false` |

고정값(`fixed`에 이유와 함께 적는다):
- 버튼 3개와 장면 3개의 짝(`data-scene`) — 장면 id가 곧 분야다.
- 배경 전환 방식: 이전 그림을 복제해 위에 두고 `moodFade` 동안 투명하게 한다. 두 배경이 겹치는 것은 의도다(시선 얼굴 칸은 겹치지 않는다는 기존 고정값과 다르다).
- 동작 줄이기에서 `moodFade`를 0으로 본다.
- 고른 버튼의 강조는 `global.accent`를 쓴다(별도 색 파라미터를 두지 않아 분야색이 한 곳에서 바뀐다).
- 버튼 터치 영역 최소 44px.

완료 기준: `layer-kit lint` 오류 0, `probe` 전 파라미터 통과, `pnpm --filter hanbok-hero check`와 루트 `pnpm check` 통과. 결과 수치는 완료 때 QA.md와 이 문서 끝에 "결과" 절을 붙여 적는다. `docs/11` §9-5 선비 표(지금 6레이어/59파라미터로 낡음, 실제 7/74)를 새 구조로 고친다.

## 6. 배경 그림 3장

- 도구: Codex `image_gen`(`codex exec`). fal은 쓰지 않는다. 참조 이미지는 화풍 `docs/참고/풍.jpg`(미추적 외부 작품, 화풍만 참조) — 카드에 역할을 적는다.
- 크기: 가로 1536 출력 → 16:9로 자르고 1920 폭으로 늘린 webp. 장당 200KB 안쪽 목표. 늘린 화질은 실제 화면에서 확인한다.
- 장소는 4장 표대로 모두 실외. 프롬프트에 한국 고유 명사(경복궁 향원정, 한옥 사랑채·서원, 인왕산)를 넣는다.
- 공통 구도: 왼쪽 45%는 어둡고 단순(이름 글자 자리), 오른쪽 가운데(선비 머리 뒤)에 시선을 뺏는 것 없음, 전체가 어두워 밝은 글자가 읽힘.
- 공통 금지: no people, no text, no calligraphy, no signboard, no hanging plaques, no nameplate, no red sun, no flags, not Chinese, not Japanese.
- 확인 절차: 분야마다 후보 2~3장 → 제가 거름(국적 단서, 글자·현판, 이름 자리 평균 밝기, 선비를 얹은 합성 미리보기) → **사용자가 고름** → 적용.
- 기록: `prompts/hanbok-hero.md` 카드 05(시)·06(서)·07(화)에 양식대로(프롬프트 원문 그대로, 버린 후보와 이유), `prompts/README.md` 표, `pnpm prompts:build`, claude.ai 보관함은 `node prompts/build.mjs --site <임시폴더>`로 만들어 `prompts/README.md`의 기존 주소로 다시 게시. 카드 03(경회루)은 교체됨으로 표시하고 그림은 `art/superseded/`로 옮긴다.

## 7. 실패 처리·접근성

- 다른 두 분야 배경은 첫 화면 `load` 뒤 한가한 때(`requestIdleCallback`, 없으면 `setTimeout`) 미리 불러온다.
- 배경을 불러오지 못하면 지금 그림을 그대로 두고 나머지 분위기(글자·색·한자·위치)는 바꾼다. 빈 배경이 되지 않는다.
- 분야 저장 키 `hanbok-hero:mood:v1`. 읽기·쓰기 예외는 잡고 이번 방문 동안만 기억한다. 값이 장면 id가 아니면 버리고 `si`로 시작한다.
- 버튼 포커스 테두리는 보이게.
- 모바일: `moods.direction` 가로, 아래쪽 가운데. 390·320px에서 가로 스크롤 없음, 이름·선비·안내와 겹치지 않음.

## 10. 구현 순서

1. 장면 3개·새 레이어·분야 버튼·전환·저장을 지금 경회루 그림 하나로 먼저 만든다(세 장면 모두 같은 배경) → lint·probe·브라우저 검수.
2. 배경 후보 생성 → 거르기 → 사용자 선택.
3. 고른 그림을 장면 `paper.image`에 넣고 분야별 값(강조색·위치)을 화면을 보며 다듬는다 → 재검수.
4. 기록·문서·허브 갱신 → 전체 check.
