# JOOHO LAB에 POTATO 등록

요청: 기존 허브에 Potato도 넣는다. 정본은 projects/jooho-lab/public이다.

참고: docs/00·10, docs/04 §0, docs/11 목록/레이어 경계, 허브 README와 기존 include-experience, Potato README·QA. 기존 작품 등록/카드/검색/소개/편집기를 재사용하고 정적 체험 스냅샷을 포함한다. 새 엔진·마을 이미지·교육 기능은 이 목록 추가에 필요하지 않아 도입하지 않는다.

레이어 계약: 추가 시각 레이어/파라미터/고정값 없음. 작품 항목은 콘텐츠이며 기존 카드 모양을 사용한다. Potato의 20개 레이어/619개 파라미터/장면·화면별 값을 그대로 포함한다. 반환 헤더는 기존 체험 템플릿을 재사용한다. 허브 전체 레이어 이관은 docs/11의 기존 미구현 범위이며 이번 등록 완료로 이관 완료를 주장하지 않는다. lint와 임베디드 probe 결과를 QA에 기록한다.

검수: registry/링크/스냅샷/build 검사, 목록·검색·분야·소개→체험→돌아가기, 건물 없는 작품의 Enter 입장, 모바일/키보드/동작 줄이기, Potato 레이어 lint/probe. 저장은 기존 편집기를 사용하며 새 저장 구현 없음.

게이트 G1~G5 PASS. 메인 런타임에서 직접 실행. powerful 비율 예외: 최종 검토 직접 수행 하드 오버라이드. 배포는 사용자 기존 사이트 수정 요청과 sites:sites 기본 게시 지침에 따라 현재 관객 범위를 유지한다. 기존 project_id 조회 NOT_FOUND, 연결된 소유 사이트 0개라 배포는 외부 접근 회복에 달려 있다. 새 사이트/ID를 만들지 않는다.

로컬 구현·검수 완료: 허브 8개 작품 검사/빌드, 전체 pnpm check, 브라우저 입장·복귀·검색·빈 결과·키보드·320px/동작 줄이기 통과. Potato lint 오류 0, 내장 probe 619/619. 새 발견: 마을 6개 건물 밖 작품의 Enter 입장이 무시되어 직접 열기 fallback을 적용했다. 기존 디자인에서 숨긴 소개 링크의 클릭을 검수했다고 주장하지 않고 소개 URL과 실제 체험 버튼을 검사했다. QA 정본은 projects/jooho-lab/QA.md. 온라인 게시 및 claude.ai 보관함 재게시 미완료.
