# JUHO LAB 포트폴리오

요청: 기존 바이브 코딩 작업물을 한눈에 보고 이동하는 3D 포트폴리오.
방향: 검은 전시 공간, 따뜻한 주황 포인트, 프로젝트 패널을 배치한 실제 WebGL 갤러리와 즉시 접근 가능한 목록. 실제 로컬 자료로만 콘텐츠 구성.
정적 HTML/CSS/ESM + Three.js, 모바일/키보드/움직임 감소와 2D 폴백. 링크 미확인 프로젝트는 소개만 제공하고 가짜 배포 링크를 만들지 않는다.
G1–G5 PASS. 범위 설계와 최종 검토는 메인 직접 수행하며 powerful 비율 예외는 하드 오버라이드 때문이다. 기존 작업물과 별도 프로젝트로 저장. Sites는 기본 비공개 배포.
