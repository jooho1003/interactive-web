# 05. 템플릿 카탈로그

양산 단위. 각 템플릿은 "완성된 최소 상태"의 앱이며, 새 프로젝트는 여기서 복제해 시작한다. 레퍼런스 사이트에서 확인된 기능만 **기본**으로, 파생에서 나온 기능은 **확장 슬롯**으로 둔다.

---

## A. `portal-space` — 3D 포탈 스페이스

**레퍼런스**: digital-figures.replit.app
**한 줄**: 얼굴을 추적해 창문처럼 들여다보는 3D 공간. 페이지 안에 씬 에디터가 있다.

### 기본 기능
| 영역 | 기능 | 설정 키 |
|---|---|---|
| 뷰 | 오프-액시스 포탈 뷰(페이스 트래킹) / 자유 카메라(드래그 회전·우클릭 팬·휠 줌) / 마우스 폴백 | `portalSettings.*` |
| 공간 | 다중 공간(SPACE 1~N), 이전/다음/목록 | `/api/spaces` |
| 오브젝트 | GLB 업로드(멀티 DnD), 위치·회전·스케일, 표시/숨김, 그림자 | `SceneObject` |
| 머티리얼 | metalness·roughness·glass(IOR)·colorIntensity·textureContrast·gamma·reflection | `SceneObject.mat*` |
| 조명 | 주광 위치·강도·색, 앰비언트, 그림자 맵, 환경맵, 안개, 글로우 | `lightSettings.*` |
| 에디터 | 레이어 패널, 멀티 선택 스케일, 히스토리(Ctrl+Z/Y), 전체 저장, 이전 저장본 불러오기 | `sync` |
| 진입 | 카메라 시작 / 마우스 모드 선택 화면 (KO/EN 병기) | `intro` |

### 확장 슬롯
- 환경 이미지 교체(`env-image`), 바닥 텍스처(`floor-texture`) — minikingdom에서 확인
- 핸드 오르빗(손 제스처) 잠금 토글 — digital-figures 버튼에 존재
- 가우시안 스플랫 렌더러 (차세대, R&D)

### 에셋 요구
- GLB 10~20개 (벽 3, 바닥 4, 소품 8~10, 캐릭터 1~2), 환경 이미지 1
- 총 ≤ 30 MB

### 적합한 의뢰
전시 갤러리, 브랜드 쇼룸, 포트폴리오 공간, 영화 세트 체험, 부스 키오스크(카메라 있는 환경)

## A'. `world-game` — 월드 게임 (A 파생)

**레퍼런스**: minikingdom.replit.app
**한 줄**: 포탈 스페이스 위에 게임 계층(메뉴·NPC·스테이지·전투)을 얹은 것.

### A에 추가되는 기능
| 영역 | 기능 | 설정 키 |
|---|---|---|
| 메인 메뉴 | SINGLE / VS / ONLINE 모드, 버튼 이미지·배경 업로드 | `main-menu-config` |
| 인증 | Clerk 로그인, GUEST 허용 | `auth: clerk` |
| NPC | NPC별 대사·음성, 관리자에서 직접 타이핑 | `npc-config/:id` |
| 스테이지 | 맵 추가, 시작 위치, 스테이지 목록 | `stages` |
| 전투 | 무기 픽업(전역), HP 바 이미지 | `weapon-pickup-global` |
| 환경 | 전역 환경 설정, 바닥 오프셋·텍스처 | `global-env-settings`, `floor-offset` |

### 강연에서 확인된 증분 순서
캐릭터 클릭 이동 → NPC 대화(대화 오가는 방식) → 관리자 탭에서 대사 타이핑 → 음성 출력 → 기즈모로 사이즈 → 맵 추가(맵은 처음부터 시작).

### 영상 2편에서 확인된 게임 명세 (Mini Kingdom)
- 조작: **얼굴 위치로 총구 조준**(카메라 필수), 스페이스바 세게 → 강한 탄, 샷건(당겨서 다발), 폭탄(주변 전멸). 몸을 좌우로 기울이면 방향.
- 스테이지 관리자: 스테이지별 적 수·배경·체력 표시·무기 이펙트·폭발 이펙트를 라이브 프리뷰로 조절.
- 스테이지 전환: Start/End 이미지로 생성한 "걸어가는" 영상 재생.
- 메뉴: 인트로 이미지에서 버튼만 분리, 배경은 영상. UI 킷 3행(기본/강조/비활성) + 폰트 킷.
- 부가: 튜토리얼 영상, 후킹 홍보 영상, 구글 로그인(스토리 모드).

### 적합한 의뢰
브랜드 미니게임, 이벤트 월드, 포트폴리오를 게임 세상으로, 교육용 탐험 콘텐츠

## B. `branching-movie` — 분기형 인터랙티브 비디오

**레퍼런스**: gryun-aimovie.com
**한 줄**: 영상 그래프를 화살표로 탐험하는 AI 영화. 디자인·자막·라우팅 전부 관리자 설정.

### 기본 기능
| 영역 | 기능 | 설정 키 |
|---|---|---|
| 그래프 | 노드(영상) / 방향 버튼(좌·상·우) / 플래그 / 조건부 글로우 / 엔딩 / 히든 | `video-flow` |
| 인트로 | 언어 선택(KO/EN), "Sound on" 안내, 오버레이·페이드 | `intro.*` |
| 버튼 | 원형 화살표 크기·색·투명도·호버·글로우 애니메이션·효과음 | `design.*` |
| 제어 | 스킵(노드별 허용), 리플레이, 언어 토글 | `skip`, `replay`, `langToggle`, `videoSkip` |
| 타이밍 | 노드별 버튼 등장 초 | `videoTiming`, `buttonShowTiming` |
| 자막 | 언어별·노드별 타임코드, 스타일(폰트·크기·위치·그림자) | `subtitles.*` |
| 오디오 | BGM 루프, 언어별 더빙 mp3 동기 | `/BGM`, `/videos/<LANG>/` |
| 캐시 | `?v=timestamp` | `storage` |
| 관리자 | 로그인 뒤(`/api/auth/user`) | `ADMIN_MODE=auth` |

### 확장 슬롯 (design-your-world에서 확인)
- Quick Jump 챕터 메뉴, Quick Edit(현재 화면 요소만 수정)
- 핫스팟(영상 위 클릭 영역, 커서 올리면 하이라이트) + 미리보기
- 질문 메뉴("Select an object to examine closely"), 히든 링크
- 포스터 프레임(`_q.png`), 모바일 저해상도(`_m1`)
- 썸네일 목록, 사용 가능 영상 자동 감지, **앱 안에서 영상 직접 업로드**
- z-index 레이어 순서 설정
- 타임라인 점프(영화 내 챕터), 이스터에그·비밀번호·히든 엔딩

### 기획 층: Connect Idea형 에디터 (`flow-editor`)
플레이어와 별도의 노드 캔버스. 장면 이미지 노드 + 선택지 엣지, 노드에서 이미지 생성, 노드 사이에서 Start/End 영상 생성, 서브 캔버스. 결과가 `video-flow` JSON. 디스크 1장 = 프로젝트 1개 메타포. 06 문서 §1-3.

### 에셋 요구
- 영상 10~15컷 (컷당 ≤ 40 MB), 언어별 mp3, BGM 1, 효과음 2(hover/click)
- 자막 JSON

### 적합한 의뢰
AI 단편 영화, 인터랙티브 프레젠테이션(강연·세미나), 브랜드 스토리, 선택형 교육 콘텐츠, 전시 안내

## D. `platform-site` — 콘텐츠 플랫폼

**레퍼런스**: objectsubjectform.com (김그륜 클라이언트 프로젝트, 강연 영상 1편에서 시연)
**한 줄**: 브랜드/커뮤니티 사이트. 문구·섹션이 설정이고, 예약·뉴스레터·후원 모듈이 붙는다. 구조는 `REPLIT ⇄ ADMIN ⇄ CLIENT`.

### 기본 기능
| 영역 | 기능 | 설정 키 |
|---|---|---|
| 사이트 | 히어로 문구, 섹션별 on/off·리셋(번호순 목록), 라이트/다크, Export All / Import | `site-settings` |
| 검증 | **Design Check** — 설정값과 렌더링 일치 확인("All matched") | `core-admin` |
| 로고 | 정방향/역방향 애니메이션 mp4 호버 | 에셋 |
| 뉴스레터 | 이름·이메일 수집, Welcome Email 편집기(발신·제목·본문·이미지·미리보기), 구독자 목록 | `/api/subscribe`, `email-templates` |
| 예약 | 트랙별(Wallet Access / Open Access) 캘린더, 잔여 슬롯, "정원 마감", 확인 이메일(Google Meet 링크), Desktop·Mobile·Email 3컬럼 프리뷰 + 레이아웃·타이포 슬라이더, 스킨 Black/White | `scheduling/*` |
| 관리자 | 관리자 체크 | `auth/admin-check` |

### 확장 슬롯
- 온체인 후원(ENS 주소, 거래 원장, RainbowKit 지갑 연결) — 지갑 번들은 지연 로드. 지갑 연결자 전용 트랙(Wallet Access) 예약. 향후 NFT 갤러리
- 구독자 Notion 미러링 (클라이언트가 노션에서 확인)
- YouTube 최신 영상 → 뉴스레터 썸네일 자동 생성
- 에피소드/아카이브 목록

### 적합한 의뢰
크리에이터 브랜드 사이트, 멘토링·워크숍 랜딩, 커뮤니티 허브, 개인 미팅 예약 사이트("자기 사이트로 초대")

## E. `visual-routine` — 비주얼 루틴/일정 앱 (신규 후보)

**레퍼런스**: 강연 2편 15:55~18:31 시연 (배포 URL 미확인)
**한 줄**: 하루를 3등분한 투두 + 캐릭터가 걸어가는 3D/일러스트 씬 + Google Calendar. 실용 앱에 스토리를 얹은 사례.

### 기본 기능
| 영역 | 기능 |
|---|---|
| 일정 | Morning / Afternoon / Evening 3컬럼, 타임라인에 깃발 꽂아 등록, 드래그로 시간 변경, 완료 시 깃발 내려감 + 폭죽 |
| 씬 | 왼쪽→오른쪽 걸어가는 캐릭터가 현재 시각 표시, 집마다 일정 깃발 |
| AI | 따라다니는 새가 "아침까지 뭐 해야 돼" 조언 |
| 설정 | 구간 경계 슬라이더(밤이 긴 사람용), 루틴 불러오기 |
| 연동 | Google Calendar 읽기/알람 (`integrations/gcal`) |

### 의미
"초창기엔 평범했다. 스토리를 넣으니 새 프로젝트가 됐다." 양산 대상이 전시·영화에 국한되지 않음을 보여주는 패밀리. 패밀리 A의 씬 셸 + `integrations`로 조립 가능.
