## A. Portal Space — digital-figures.replit.app

### 사용자 경험
- 진입: "카메라로 시작 / START WITH CAMERA" 또는 "카메라 없이 마우스로 보기 / Mouse Mode".
- 카메라 허용 시 얼굴 위치로 뷰가 움직이는 오프-액시스 프로젝션. 카메라 없으면 마우스 모드로 자동 폴백 (버튼 툴팁: "카메라가 인식되지 않아 마우스 모드로 동작 중입니다").
- 폐허 방 안에 매트릭스풍 인물 2명, 책상·랩탑·전화·랜턴·의자. 10개 공간(SPACE 1~10)을 이전/다음으로 이동.

### 에디터 UI (페이지에 그대로 노출)
버튼 목록 (접근성 트리에서 확인):
- 오프-축 포탈 뷰 (페이스 트래킹) / 3D 씬 자유 카메라 (드래그: 회전, 우클릭: 팬, 휠: 줌)
- Hand orbit lock 토글
- 레이어 패널 / 오브젝트 추가 / 히스토리 패널 (Ctrl+Z/Y)
- 씬 전체 저장 / 이전 저장본 불러오기 / GLB 파일 추가
- Light Settings / Settings
- 이전 공간 / 스테이지 목록 / 다음 공간

→ 강연에서 말한 "레이어·기즈모·멀티 선택·저장"이 전부 들어 있다. 이것이 **툴**이다.

## B. AI MOVIE — gryun-aimovie.com

### 사용자 경험
- 진입: 어두운 무대 영상 위 "Select a language / Sound on / Korean / English", 하단 "Created by Gryun Kim".
- 언어 선택 → 인트로 → 영상이 끝나갈 때 화살표 버튼(좌/상/우)이 나타나고, 선택에 따라 다음 영상으로 분기. 빨간 글로우가 "권장 경로"를 알려준다.
- BGM은 별도 mp3, 영상 음성도 언어별 mp3(`/videos/video1.mp3`)로 분리 → 영상 하나에 다국어 더빙.

### 데이터 모델

`GET /api/video-flow` — 영상 그래프
```json
{
  "startVideo":"video1", "buttonShowTiming":8,
  "videos":{
    "video1":{"file":"video1.mp4","buttons":["right"],"defaultGlow":"right",
              "navigation":{"right":"video2"},"src":"/videos/video1.mp4?v=1765560766000","available":true},
    "video3":{"file":"video3.mp4","buttons":["left","up","right"],"defaultGlow":"up",
              "glowCondition":{"if":"visitedVideo3In","then":"right"},
              "navigation":{"left":"video3-L","up":"video3-IN","right":"video4"}, ...},
    "video3-IN":{"file":"video3-IN.mp4","buttons":["right"],"setsFlag":"visitedVideo3In", ...},
    "video5-IN":{"file":"video5-IN.mp4","buttons":[],"defaultGlow":null,"isEnding":true,"navigation":{}},
    "video6-HIDDEN":{"isEnding":true, ...}
  },
  "copyright":"Created by Gryun Kim", "availableFilesCount":14, "totalVideosCount":15
}
```
핵심 개념:
- **노드** = 영상 파일 1개. `buttons`로 어떤 방향 버튼이 뜨는지, `navigation`으로 방향→다음 노드.
- **플래그**: `setsFlag`로 방문 기록, `glowCondition`으로 "이미 본 곳이면 다른 버튼을 빛나게".
- `available:false`인 노드가 2개 → 파일이 아직 없어도 그래프는 먼저 설계할 수 있다.
- `?v=타임스탬프`로 캐시 무효화.
- 히든 엔딩(`video6-HIDDEN`) 존재.

## 모노레포로 가져갈 설계 원칙 (여기서 도출)

1. **설정은 전부 JSON, UI는 JSON을 편집하는 폼.** desktop/mobile 두 벌을 기본으로.
2. **씬/그래프 데이터와 미디어 파일을 분리.** 파일은 스토리지, 참조는 DB. `?v=timestamp` 캐시버스팅.
3. **`saved-at` 폴링 같은 동기화 신호**를 공용 모듈로.
4. **폴백 우선**: 카메라 없으면 마우스, 영상 없어도(`available:false`) 그래프는 동작.
5. **에디터를 프로덕션에 노출할지 여부는 플래그로.** A는 노출, B/D는 로그인 뒤. 둘 다 같은 코드여야 한다.
6. **복제가 전제**: 앱 이름·타이틀·파비콘·도메인이 한 곳(설정)에 있어야 minikingdom처럼 타이틀이 남는 실수를 막는다.
