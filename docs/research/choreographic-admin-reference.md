# Choreographic을 참고한 장면 편집 관리자 UI 제안

2026-09-23. 상태: **레퍼런스 검토·UX 제안**, 앱 구현 또는 기존 설계 대체가 아님.

## 확인한 근거

- [사용자가 제공한 App Store 페이지](https://apps.apple.com/kr/app/id1608391996): 포메이션·전환 시간 조절, 맞춤 이동 경로, 2D/3D 미리보기, 소품·노트·권한 설명 확인.
- [공식 사이트](https://www.choreographic.app/): 무대 시각화, 전환 스크러빙, 포메이션과 전환 길이 구분, 음악 동기화 설명 확인.
- [공식 전환 이미지](https://framerusercontent.com/images/6vQJyaZrNGM6MTOwrKF5r5lpidk.png?height=2426&width=2488): 위쪽 장면 상태와 아래쪽 썸네일·전환 구간 연결을 육안 확인.

앱을 설치·실행한 검수는 아니다. 아래 기능과 배치는 우리 관리자에 대한 설계 제안이다.

## 가져올 핵심 방식

포메이션은 장면 상태, 댄서·소품은 이미지·텍스트·버튼 레이어, 이동 경로는 레이어 모션, 포메이션 간 전환은 장면 사이 전환으로 대응시킨다. 장면 썸네일을 고르면 미리보기와 선택 레이어의 설정이 함께 바뀌게 한다.

## 하나의 편집 작업 공간

- 상단: 작품/페이지 선택, 편집·체험 모드, 데스크톱·모바일, 초안 상태, 되돌리기, 변경 확인·게시.
- 왼쪽: 선택 장면의 레이어. 배경, 캐릭터, 문구, 버튼, 효과. 표시/숨김·잠금·선택.
- 중앙: 실제 앱 렌더러의 미리보기. 편집 모드에서는 클릭이 레이어 선택이고, 체험 모드에서는 실제 작품 동작이다.
- 오른쪽: 선택 대상의 이미지 교체·문구·위치·크기·회전·모션·트리거·다음 장면. 현재 수정 범위(페이지/상태/화면 크기)를 항상 표시.
- 아래: 페이지·장면 썸네일 스트립. 선택 장면의 동작을 펼치면 등장·유지·퇴장/전환을 스크러빙하고 재생.
- 흐름 보기: 분기 연결을 확인·수정하는 별도 보기. 장면·레이어 선택은 기본 보기와 공유.

## 시간을 해석하는 규칙

1. URL 페이지, 페이지 안의 상태, 그 상태의 레이어를 구분한다. Potato의 brand/digital/character는 같은 페이지의 상태이며 Work/About/메모는 모달 상태다. 모두 강제 자동 재생 페이지로 바꾸지 않는다.
2. 기본 썸네일 목록은 탐색 순서다. 분기형 작품의 실행 순서는 연결이 결정한다. 목록 위치만 바꿔 분기 연결을 조용히 수정하지 않는다.
3. 시간 기반 모션은 해당 장면 안의 상대 시간으로 표시한다. 스크롤 모션은 진행률 0–100%, 클릭은 이벤트로 표시한다. 사용자 입력 대기는 고정된 초로 위장하지 않는다.
4. 전체 체험은 분기 지점에서 실제 선택을 기다린다. 연속 검수에는 선택 경로를 명시한 재생을 제공한다.
5. 과거 시점으로 스크러빙하면 같은 초기 상태에서 같은 결과를 렌더링한다. 결제·발송·실제 게시 같은 외부 효과를 재실행하지 않는다.

## 기존 설계와의 관계

- [09 흐름·미디어 설계](../09-흐름-에디터-미디어-관리-설계.md): 이야기 연결·미디어·초안/게시의 책임을 유지한다.
- [11 레이어 시스템](../11-레이어-설정-시스템-설계.md): 위치·크기·문구·색·입력 반응·장면별/화면별 값의 책임을 유지한다.
- 이 제안은 두 설계의 공통 편집 셸과 장면 탐색 UX를 구체화한다. 별도 데이터 원본을 추가하지 않는다.
- 11의 1단계에는 키프레임 타임라인이 제외되어 있다. 우선 기존 등장·전환 프리셋의 길이·지연·곡선과 스크러빙부터 구현하고, 임의 키프레임·곡선 경로는 별도 범위 확장으로 다룬다.
- 관리자 전용이라는 요구는 버튼 숨김이나 `?edit=1`로 충족되지 않는다. 배포 환경에서는 인증·서버 측 읽기/쓰기 권한으로 초안과 게시 기능을 보호해야 한다. 공개 로컬 편집 옵션은 이번 관리자 전용 경로와 분리한다.

## 첫 구현의 완료 조건

페이지/상태 선택 → 레이어 선택 → 이미지·위치·모션 변경 → 앞뒤 장면 미리보기 → 변경 취소/초안 저장이 한 화면에서 된다. 모바일 값과 전체 공통 값의 적용 범위를 혼동하지 않는다. 게시 전 변경 요약과 이미지 누락·끊긴 이동 검사가 가능하다. 시각 조절은 실제 앱 렌더러에 반영되며 관리자 미리보기만 별도로 흉내 내지 않는다.

재사용 교훈: 관리자도 기능 폼을 늘어놓기보다 **장면을 고르고, 대상으로 조절하고, 전후를 재생하는 흐름**을 중심으로 설계한다. 무조건 시간축으로 바꾸지 말고 앱의 실제 입력·분기 모델을 유지한다.
