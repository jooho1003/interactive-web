# 오픈소스 3D·영상 생성 검토 — Tripo·fal.ai를 로컬 오픈소스로 대체할 수 있나

조사 기준일: 2026-09-30
조사 방법: 리서치 에이전트 2개가 WebSearch/WebFetch로 공식 GitHub·Hugging Face·가격 페이지와 순위표를 확인. 테스트 에이전트 1개가 Hugging Face 무료 서버(ZeroGPU)에서 같은 이미지로 오픈 3D 모델을 실제로 돌려 봄. 순위·가격 수치는 에이전트가 출처에서 가져온 값이며 직접 대조하지 않음.

---

## 결론 요약

3D는 Tripo, 영상은 fal.ai를 그대로 쓴다. 오픈소스로 바꿔도 품질이나 비용에서 얻는 게 적다.

- **3D:** 한국에서 쓸 수 있는 오픈 모델은 사실상 TRELLIS.2 하나다. 사람 투표 순위에서 Tripo와 격차가 크고, JOOHO LAB에 필요한 스마트 로우폴리 기능도 없다.
- **영상:** 가중치가 공개된 Wan은 2.2가 마지막이다. fal.ai에서도 Wan 2.2가 가장 싸서, 로컬로 돌려 아끼는 금액이 작다.
- **로컬 실행:** 노트북은 NVIDIA GPU가 없어 3D·영상 모두 불가다. 집 데스크톱 3060 Ti 8GB는 영상만 느리게 가능하다.

## 하드웨어 현황

오픈 3D 모델은 두 장비 모두에서 못 돌리고, 영상은 데스크톱에서만 돌릴 수 있다.

| 장비 | GPU | 시스템 RAM | 오픈 3D 모델 | 영상 (WanGP) |
| --- | --- | --- | --- | --- |
| 노트북 (Core Ultra 7 255H) | Intel Arc 140T 내장 (공유 최대 16GB) | 31GB | 불가 | 불가 (Intel 미지원, CPU만으로는 비현실적) |
| 집 데스크톱 | RTX 3060 Ti 8GB | 미확인 | 불가 (TRELLIS.2는 24GB 필요) | 가능, 느림 |

주요 오픈 모델은 NVIDIA CUDA 전용 연산을 쓴다. Intel Arc에서 동작이 확인된 버전은 없다.

## 3D: 오픈소스 이미지→3D 후보

Tripo를 대체할 만한 후보는 TRELLIS.2뿐이고, 품질 순위와 기능 모두 Tripo보다 낮다. 순위는 [top3d.ai](https://www.top3d.ai/leaderboard)의 3D Arena 사람 투표 기준이다.

| 모델 | 공개 | 라이선스 | 필요 GPU | 순위 (Elo) | Tripo 대비 |
| --- | --- | --- | --- | --- | --- |
| [Tripo](https://www.tripo3d.ai/features/low-poly-3d-model-generator) v3.1 (기준) | 상용 API | 유료 | 필요 없음 (클라우드) | 1위 (1133) | 쿼드 메시, 자동 리깅, 부위 분리, 스마트 로우폴리 |
| [TRELLIS.2-4B](https://huggingface.co/microsoft/TRELLIS.2-4B) | 2025-12 | MIT, 상업 이용 가능 | NVIDIA 24GB 이상, 리눅스 | 17위 안팎 (약 959) | 조밀한 메시, 쿼드·리깅·부위 분리 없음 |
| [Hunyuan3D-2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1) | 2025-06 | EU·영국·한국 제외 | NVIDIA 10~29GB | 미확인 (비공개 3.1은 5위) | 한국에서 사용 불가 |
| [Step1X-3D](https://github.com/stepfun-ai/Step1X-3D) | 2025-05 | Apache 2.0 | NVIDIA 27~29GB | 순위 없음 | 품질 미확인, 데모 서버 중지 |
| [SAM 3D Objects](https://ai.meta.com/blog/sam-3d/) | 2025-11 | Meta 제한 라이선스 | 미공개 | 21위 (768) | 실사 장면용, 스타일화 에셋에 약함 |
| [TripoSG](https://github.com/VAST-AI-Research/TripoSG) | 2025-02 | MIT | NVIDIA 약 8GB | 순위 없음 | 형태만 만듦, 텍스처 없음 |

조사상 Tripo는 2026-09-21에 쿼드 메시를 기본 출력하는 [P2.0](https://www.voxelmatters.com/tripo-ai-launches-p2-0-model-to-generate-native-quad-meshes-for-production-pipelines/)을 냈다(미확인).

## 3D: 무료 서버 비교 테스트

같은 이미지 2장(방패 문장, 가네샤 흉상)으로 오픈 모델 3개를 돌렸지만 GLB는 하나도 나오지 않았다. 모두 로그인 없이 Hugging Face 무료 서버에서 시도했다.

| Hugging Face 서버 | 결과 | 실패 원인 |
| --- | --- | --- |
| microsoft/TRELLIS.2 | 실패 | 생성은 한 번 85.8초 만에 끝났지만 GLB 추출 단계에서 세션이 끊김. 이후 재시도는 모두 빈 오류 |
| tencent/Hunyuan3D-2.1 | 실패 | 서버 API 스키마 오류 (선택 입력의 null을 거부) |
| trellis-community/TRELLIS | 실패 | 생성 단계에서 빈 오류 |

빈 오류는 로그아웃 사용자의 작은 무료 GPU 한도 때문으로 추정한다. 서버가 실제 오류를 숨겨서 확정은 못 했다. 다시 하려면 무료 Hugging Face 계정 토큰이나 유료 GPU가 필요하다.

## 영상: WanGP와 오픈 Wan 현황

[WanGP](https://github.com/deepbeepmeep/Wan2GP)는 NVIDIA·AMD GPU만 지원해서 노트북에서는 못 돌린다.

- **지원 GPU:** NVIDIA GTX 10 시리즈~RTX 50 시리즈, AMD RDNA 2~4. Intel Arc는 지원하지 않는다. 같은 계열 노트북 사용자가 CUDA 오류로 막힌 [이슈](https://github.com/deepbeepmeep/Wan2GP/issues/1998)가 열려 있다.
- **최소 VRAM:** 일부 모델 약 6GB, 권장 10GB 이상. 큰 모델은 시스템 RAM 64GB를 권장한다.
- **지원 모델:** Wan 2.1/2.2, LTX-2 계열, HunyuanVideo 1/1.5, MiniMax H3, Qwen Image, Flux 등([목록](https://github.com/deepbeepmeep/Wan2GP/blob/main/docs/MODELS.md)).
- **오픈 Wan:** 가중치가 공개된 Wan은 2.2(Apache 2.0)가 마지막이다. Wan 2.5, 2.6, 2.7, 3.0은 API로만 제공된다.

## 데스크톱 3060 Ti 활용 판단

최종 결과물은 fal.ai로 뽑고, 3060 Ti는 시안을 많이 돌려 볼 때만 쓴다.

- **3D:** VRAM 8GB로는 TRELLIS.2(24GB)가 돌아가지 않는다.
- **영상, 작은 모델:** Wan 2.2 5B, 1.3B, LTX 계열은 8GB로 무난하다.
- **영상, Wan 2.2 14B:** 모델 일부를 시스템 RAM으로 넘겨 돌린다. RAM 32GB 이상이 필요하고 꽤 느리다.
- **속도:** 5초 클립 기준 작은 모델은 몇 분, 14B는 수십 분으로 추정한다. 직접 잰 값은 아니다.
- **비용:** fal.ai Wan 2.2로 5초 클립은 $0.2~0.4이고 10초 안팎이면 끝난다. 몇 개 뽑는 수준이면 fal.ai가 낫다.
- **로컬이 의미 있는 경우:** 프롬프트를 수십~수백 번 바꿔 보는 시안 작업, LoRA 같은 커스텀 모델 실험.
