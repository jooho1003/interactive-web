# Scene Studio 관리자 설계 · Potato Designer 1차 구현

설계 확정: 2026-09-23. 대상은 Potato Designer와 공용 `@iw/layer-kit`의 첫 소비자다. 다른 세 앱의 이관과 원격 게시 API는 [11번 전체 시스템 설계](11-레이어-설정-시스템-설계.md)의 후속 단계다. 이 문서는 이번에 실제 만드는 범위와 동작을 확정한다. 검수 결과는 [Potato QA](../projects/potato-designer/QA.md)에 기록한다.

## 참고와 적용

[Choreographic 조사](research/choreographic-admin-reference.md)의 장면 카드 → 실제 미리보기 → 선택 요소 수정 → 재생 확인 순서를 채택했다. 앱 화면을 복제하거나 무용의 음악·박자 모델을 포트폴리오에 강제하지 않는다. [09번](09-흐름-에디터-미디어-관리-설계.md)의 콘텐츠/흐름과 [11번](11-레이어-설정-시스템-설계.md)의 시각 레이어를 분리한다. “학습”은 이런 판단과 검수 결과를 에이전트가 다음 작업에서 참고하도록 기록하는 뜻이다.

## 작업 화면

- 상단: 저장 상태, 되돌리기/다시 하기, 변경 비교, 로컬 게시.
- 왼쪽: 그룹별 레이어 목록과 검색. 화면에서 클릭해도 같은 레이어가 선택된다.
- 가운데: 페이지 순서, 실제 작품 iframe, 재생/일시정지/시점 이동, 세 가지 장면 카드.
- 오른쪽: 선택한 레이어의 속성, 적용 장면·화면 범위, 속성 또는 범위 초기화. 보이기·불투명도·이동·배율·회전·문구·이미지·모션은 기본 영역에, 타이포그래피·여백·상태별 디자인은 접은 영역에 둔다.
- 아래: JSON 가져오기/내보내기, 이전 게시본 복구, 게시본으로 초안 되돌리기.

편집 모드에서는 작품의 클릭을 선택/드래그로 사용한다. 직접 체험 모드에서는 원래 버튼·검색·상세·프로젝트 메모가 동작한다. 게시본 비교를 켜면 저장한 게시값을 같은 렌더러에 적용한다. 수정하면 비교를 해제하고 초안으로 돌아온다.

## 페이지, 장면, 시간의 구분

| 축 | 구성 | 의미 |
|---|---|---|
| 페이지 | 홈, 작업 모음, 작업 상세, 소개, 프로젝트 메모 | 관리자가 확인할 실제 UI 상태. 모달도 페이지 순서에 포함한다. |
| 장면 | Brand, Digital, Character | 배경·색·단어·캐릭터 자세 등 시각 상태 |
| 화면 | 1440 데스크톱, 1920 와이드, 768 태블릿, 390 모바일 | iframe의 실제 CSS viewport. 전체 화면을 줄여 표시하므로 반응형 CSS가 실제로 작동한다. |
| 시간 | 2초/8초/40초 구간과 시점 이동 | 기존 CSS 애니메이션의 시점. 페이지 이동이나 사용자 클릭 대기를 자동으로 통과하지 않는다. |

기본 미리보기는 등장 모션 뒤의 2초다. “처음”은 0초로 간다. 등장·부유·그림자·흐르는 띠·패널 등장 모션의 시간, 시작 지연, 속도 곡선을 수정한다. 임의 키프레임 추가, 분기 그래프 작성, 음악 트랙 편집은 이 버전의 기능이 아니다. OS 동작 줄이기는 실제 작품에서 계속 우선한다.

## 레이어와 값

20개 레이어: 전역, 배경 종이, 배경 글자, 십자 표시, 연도, 무대, 그림자, 캐릭터, 머리글, 소개 문구, 재생 도장, 분야 선택, 하단 안내, 흐르는 띠, 바닥글, 패널 공통, 소개 패널, 작업 카드, 작업 패널, 메모 패널.

매니페스트는 순수 JSON을 내보내는 ES 모듈이다. 11번의 `defineLayers`/traits 작성 편의 API는 아직 제공하지 않으며, 런타임에 필요한 id·selector·type·default·bounds·scene·breakpoint 계약을 직접 선언한다. 세부 디자인의 복합 CSS는 매니페스트가 허용한 프리셋 선택지로 제한하고 자유 CSS 입력은 받지 않는다.

값 파일은 `iw-layers/1`의 `base`, `responsive`, `scenes[scene].base`, `scenes[scene].responsive`를 사용한다. 적용 순서는 기본값 → 공통 수정 → 화면 기본/수정 → 장면 기본/수정 → 장면×화면 수정이다. “모든 장면”은 공통 기본값을 편집한다는 뜻이며, 더 구체적인 장면값이 우선하면 인스펙터에 표시한다. 초기화는 그 범위의 override를 제거하여 상속값을 드러낸다.

패널 공통 이동/회전은 개별 패널값에 더하고, 크기/불투명도는 곱한다. 숨기기는 하위 레이어의 표시 설정보다 우선한다. 그리드/플렉스 구조, 모달의 열기/닫기, 포커스 표시, 동작 줄이기와 기능 상태는 고정 구조이며 manifest.fixed에 이유를 기록한다. 작업 제목·태그 등 목록 콘텐츠는 `work-data.js`가 계속 소유한다.

## 저장과 복구

1. 입력 즉시 같은 작품 런타임에 반영한다. 드래그 한 번/슬라이더 한 번은 되돌리기 한 단계다. 최대 60단계의 세션 기록을 둔다.
2. 마지막 수정 후 450ms에 서버 초안을 저장한다. 저장 중 추가 입력을 직렬화하고 가장 최근 값까지 저장한다.
3. 저장 실패/다른 창의 변경이 있으면 현재 메모리 초안을 보존하고 오류를 표시한다. 자동 덮어쓰기를 멈추며 JSON 내보내기를 사용할 수 있다.
4. 로컬 게시 전에 게시본과 초안의 차이를 보여준다. 확인 시 최신 초안을 저장하고 작품 값·CSS·런타임·첫 화면 HTML을 갱신한다.
5. 직전 게시값을 버전 파일로 보관한다. 이력 복구는 초안만 바꾸며, 다시 게시해야 공개 화면에 적용된다.

가져오기는 작품·버전·스코프·파라미터 타입·범위를 모두 검사한다. 알 수 없는 값은 조용히 버리지 않고 오류로 반환한다. 텍스트는 textContent/HTML escape만 사용한다. 이미지는 최대 2MB PNG/JPEG/WebP, 미리보기는 data URL, 게시 시 해시 파일명으로 로컬 자산에 저장한다. 초안은 `.studio/`에 두고 Git에서 제외한다.

## 관리자 경계와 게시 의미

이 버전은 **신뢰할 수 있는 단일 사용자 컴퓨터의 로컬 제작 도구**다. 서버는 127.0.0.1에만 바인딩한다. Host와 쓰기 요청 Origin을 검사하고 HttpOnly/SameSite=Strict 세션으로 관리자 자산과 API를 보호한다. `ADMIN_PASSWORD`를 설정하면 로그인 후에만 세션을 발급한다. 비밀번호를 설정하지 않은 기본 모드는 로컬 `/admin` 방문자를 신뢰한다. 이것을 원격 서비스용 사용자 인증이라고 간주하지 않는다.

관리자 HTML/JS는 `admin/`에 있고 정적 공개 디렉터리 `dist/` 밖에 있다. 정적 사이트 배포에는 관리자나 쓰기 API가 포함되지 않는다. 버튼의 “로컬 게시”는 이 컴퓨터의 파일 갱신이다. 외부 배포·클라우드 계정 변경·프로덕션 데이터베이스 연결을 수행하지 않는다. 원격 운영 시에는 서버 측 소유자 인증과 저장소/충돌 어댑터를 먼저 구현해야 한다.

## 검수 계약

공용 값 해석/검증 테스트, 임시 디렉터리 서버 통합 테스트, 매니페스트와 CSS 바인딩 lint, 생성물 최신성 검사를 제공한다. 브라우저에서는 원래 작품의 92개 회귀 항목과 관리자 입력→초안→게시→새로고침→복구를 검사한다. `probe`는 실제 DOM의 계산 스타일/텍스트/이미지 속성/키프레임이 파라미터 변경으로 달라지는지 확인한다. 상태별 CSS는 원래 미디어·hover 조건을 검수 중 활성화하며 결과에서 조건부 항목을 구분한다. 전체 시각 조합의 디자인 품질을 자동 검사했다고 주장하지 않는다.
