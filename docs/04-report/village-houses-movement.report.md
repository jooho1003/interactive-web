# Village houses and movement · Report

2026-10-05 · JOOHO LAB · bkit Plan→Design→Do→Check→Act→QA→Report

선비와 종말의 탑의 중복 좌표 및 한 칸으로 제한된 드래그를 확인했다. 독립 한옥을 추가해 실제 집8채를9채로 만들었고, 입력 거리만큼 이동하며 종료 위치를 유지하도록 수정했다. 모바일 이름표 클릭 방해와 끝 경계 이탈도 검수에서 발견해 해결했다.

데스크톱·390px·320px 거리 이동/입장/복귀 검수 통과, full motion 터치와 세로 스크롤 통과, 공용43+집108개 파라미터의 데스크톱·모바일 probe 통과. 앱 check/build 및 프롬프트·레퍼런스 보관함 빌드 완료. 정확한 실행 결과·캡처·확인 한계는 [QA-village](../../projects/jooho-lab/QA-village.md)에 기록한다.

재사용: 목록 길이·링크 수뿐 아니라 독립 건물 좌표와 실제 입장을 확인한다. 드래그는 선택 인덱스 대신 시작 카메라 위치를 사용한다. 카메라 끝 경계는 장식 그림 끝뿐 아니라 마지막 목적지 가시성을 함께 고려한다. 새 비주얼은 docs/14의 파노라마 예외를 따르며 프롬프트 원문은 정본에 남긴다.
