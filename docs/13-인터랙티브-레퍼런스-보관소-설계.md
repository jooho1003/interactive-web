## 패턴 색인 `patterns.md`

에이전트는 사이트 이름이 아니라 **만들려는 상호작용**으로 찾는다. 패턴 항목에 사례 목록은 손으로 쓰지 않는다. 빌드가 카드의 패턴 칸에서 모아 보관함과 `catalog.json`에 넣는다. 같은 정보를 두 군데에 적어 어긋나는 일을 막기 위해서다.

````markdown
### `desktop-os` — 데스크톱 OS 은유

작품·정보를 창·아이콘·폴더로 연다. 방문자가 이미 아는 조작(더블클릭, 창 닫기)을 탐색으로 쓴다.

| 항목 | 내용 |
|---|---|
| 맞는 의뢰 | 작업물이 많은 개인 포트폴리오, 레트로 콘셉트 |
| 패밀리 | D에 가까움 |
| 레이어 대응 | 배경화면, 아이콘 그리드, 창 프레임, 창 내용, 작업 표시줄 — 창 크기·위치·열림 모션·아이콘 간격 |
| 검수할 점 | 창 포커스 순서, Escape로 닫기, 모바일에서 창 대신 전체 화면 |
````

첫 후보 7개(사이트 확인 후 확정): `desktop-os` 데스크톱 OS 은유 · `drive-to-explore` 게임형 공간 탐색 · `moodboard-canvas` 자유 배치 무드보드 · `hand-drawn` 손그림 표현 · `illustration-hero` 일러스트 히어로 모션 · `expand-gallery` 클릭하면 펼쳐지는 갤러리 · `motion-bg-hero` 움직이는 배경 히어로. 확정 목록은 [references/patterns.md](../references/patterns.md)에 있다. 사이트를 직접 확인한 뒤 motion-bg-hero는 video-tile-catalog로 바뀌었다(2026-09-30).

## 노션 → 저장소 가져오기

1. 사용자가 Instagram 리서치 행의 Tags에 `인터랙티브 참고`를 붙인다. DB 구조는 그대로이고 태그 선택지만 늘어난다.
2. 사용자가 "레퍼런스 가져와"라고 하면 에이전트가 노션 커넥터로 태그가 붙은 행을 조회한다. 행 필터 조회가 막히면 뷰 전체를 읽고 걸러 낸다.
3. `catalog.json`의 노션 id·주소와 비교해 새 행과 새 사이트만 고른다.
4. 행 본문에서 사이트 주소를 뽑는다. 한 행에 여러 사이트가 있을 수 있다.
5. 사이트마다 Aside로 직접 열어 캡처·녹화·관찰하고 카드를 쓴다. 새 패턴이 나오면 `patterns.md`에 추가한다.
6. `pnpm references:build` → `pnpm check`. 보관함을 다시 게시한다.
7. 노션에는 되쓰지 않는다(외부 쓰기 최소화). 가져온 결과는 사용자에게 카드 목록으로 보고한다.

노션 커넥터가 없는 세션(Codex 등)은 가져오기를 하지 않고 `references/`를 읽기만 한다. 이번 두 행은 태그 없이 바로 가져온다.

## 에이전트가 쓰는 방법 (AGENTS.md 변경)

"매 작업의 순서"에 넣는 문구:

- 2단계 끝: "외부 사이트 레퍼런스는 `references/patterns.md`에서 이번 상호작용에 맞는 패턴을 찾아 카드 2~3개를 읽는다. 맞는 패턴이 없으면 '해당 없음'이라고 적는다."
- 3단계: 계획 항목에 "**참고 레퍼런스**: 카드 id · 가져올 것 · 안 가져올 것 · 레이어 계약에 반영할 파라미터"를 추가한다.
- 5단계: "실제로 참고한 레퍼런스 카드의 '쓰인 작품'에 작품을 적는다."

새 절 "외부 레퍼런스 — 참고만":

- 원본은 `references/`다. 가져오는 절차는 `references/README.md`에 있다.
- 레퍼런스의 문구·이미지·브랜드·코드는 그대로 옮기지 않는다. 상호작용 방식을 우리 레이어와 데이터로 다시 설계한다.
- ⏸ 미확인 카드는 근거로 단정하지 않는다. ⚠️ 카드나 확인한 지 90일이 넘은 카드는 쓰기 직전에 사이트가 살아 있는지 다시 본다.
- 유료 프롬프트·계정이 필요한 자료의 본문은 저장소에 옮기지 않는다.

`docs/00` 문서 표와 `docs/10` "기존 자료에서 가져올 원칙" 표에 한 줄씩 넣는다.

## 보관함

- 로컬 `references/gallery.html`, 어느 기기에서나 보는 claude.ai 페이지(비공개). claude.ai 주소는 처음 한 번 만들고 README에 적은 뒤, 이후에는 `node references/build.mjs --site <임시폴더>`로 만든 `index.html`·`media/`를 같은 주소에 다시 게시한다.
- 기능: 패턴·패밀리·확인 상태 필터, 검색, 썸네일 크게 보기와 녹화 재생, 원본 사이트 열기, **플랜용 요약 복사**.
- 플랜용 요약 형식:

```text
[레퍼런스] bychudy — Chudy Miłosz (https://www.bychudy.com/) · 패턴 desktop-os · ✅ 2026-10-01
가져올 것: …
안 가져올 것: …
```
