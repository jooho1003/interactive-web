## 한 줄 요약

**"작품을 하나씩 만들지 말고, 작품을 찍어내는 툴을 만든다."**
관리자 페이지가 붙은 베이스 프로젝트 3~4개를 만들어 두고, 새 의뢰가 오면 복제해서 기능만 얹는다. 강연자는 이 방식으로 8개 예제를 동시에 굴렸고, 실제로 minikingdom(게임)은 digital-figures(포탈 갤러리)를 복제한 흔적이 페이지 타이틀에 그대로 남아 있다.
