# 공간 레이어 편집 설계

## 상태 및 저장

`spatial-layers.js`의 gallery 분기만 새 편집 모듈에 연결한다. 동네 설정은 기존 경로를 유지한다. layerHost.values가 즉시 화면에 적용되는 draft이고 saved 스냅샷이 브라우저 저장 기준이다. Save만 localStorage를 변경한다. 닫아도 draft를 유지하고 열기 버튼에 미저장 표시한다. 저장본 복구/한 단계 되돌리기/초기화/JSON 내보내기로 복구한다. 저장 오류는 draft를 유지하고 실패 상태와 내보내기 경로를 알린다.

## 입력과 장면

우측 nonmodal 패널에 장면/화면 범위, 레이어 선택, 좌표와 기존 파라미터를 둔다. 3D pick/ray/outline API는 scene이 제공하고 editor만 layerHost를 갱신한다. DOM 선택은 manifest selector를 따른다. 선택 영역의 이동 손잡이와 화면 직접 클릭·끌기, 방향키, 숫자 입력을 제공한다. Ctrl/Cmd+S는 모드 내 저장. Escape는 드래그 취소 후 모드 닫기. pointercancel/lost capture는 드래그 시작값 복구.

나무 선택 시 외관, POTATO 선택 시 작품 장면을 보여 준다. 장면 이동은 편집 중 즉시 완료하며 포인터·수동 카메라 입력을 잠근다. 선택 테두리는 실제 투영 경계를 사용하고 3D drag는 시작점과 동일 평면에서 계산한다. 데스크톱에서 패널 공간을 확보하고 편집 중 외관 화각만 임시 확장한다. 닫으면 기존 화각으로 돌아간다. 모바일은 하단 패널과 목록·숫자 입력으로 조작한다.

## 범위

건물 모델·UV·카메라 경로 재구성은 이번 범위에 없다. stage 위치는 전체 3D 렌더 화면의 이동이다. 나무의 실제 좌표와 POTATO 그림자/캐릭터 좌표는 각각 독립적으로 이동한다. 건물 침범 방지는 renderer의 기존 안전 계산이 최종 적용 위치를 결정한다.
