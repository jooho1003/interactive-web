# 전시관 건물 외관 시범 · Design

2026-10-05 · [Plan](../../01-plan/features/gallery-museum-exterior.plan.md)

## 건축
기존18m 전시관 폭과 내부7칸/가구/조명은 재사용한다. 앞쪽 x=-9..-3, 3..9에 높이6.9m의 석재 외벽과 낮은 수평 창을 둔다. 두 매스를 위에서 잇는 석재 보는 y=6.625m 아래를 비워 중앙6m 통로를 만든다. 안쪽 기존문 x=±1.75m와 내부 천장/동선은 그대로 둔다. 기존 얇은 지붕의 앞쪽 돌출을 줄여 새로운 매스가 보이게 한다.

## 구현/설정
`build-spatial-lab.py`의 외관 지오메트리만 수정하고 기존7종 PBR·UV0 조명/AO·UV1 반복 재질 export를 재사용한다. 색/마감/조명은 stage 설정을 사용한다. `spatial-route.js` 외부 eye/look만 새 높이에 맞춰 넓힌다. 모델 뒤에서 자동으로 들어가는 기존 routeTo의 중앙 문 통과는 보존한다.

## 검증
새 외벽 AABB와 외부→홀/작품→외부 경로를 조밀하게 샘플링해 여유를 검사한다. 기존 브라우저 QA의 전환/포인터/터치/키보드/검색·빈 결과/동작 줄이기/레이어 probe와 세 화면 캡처를 재사용한다. 자산 변경만 하므로 새 저장 경로는 없다. 이전 GLB/packed Blender/외관 캡처를 art/gallery-museum-exterior에 보존한다.
