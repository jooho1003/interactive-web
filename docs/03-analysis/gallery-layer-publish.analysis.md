## 리뷰·조정

gallery_review가 API capability 읽기 실패를 정적 환경으로 오인하는 결함을 발견했다. 404만 미지원으로 인정하고 다른 상태/JSON/검증 오류는 저장을 차단하도록 수정했다. 그 네 오류 경로의 UI를 추가 검수했다. 서버 원자적 쓰기·직렬화·revision 및 저장 중 추가 편집에는 중요한 리뷰 결함이 없었다.

## 확인 한계와 다음 사용 조건

현재 연결 탭에서 내보낸 값은 빈 override였다. 사용자는 Chrome에서 편집했다고 답했으며 Chrome은 원격 디버깅 포트가 없어 원본 배치를 직접 읽지 못했다. 프로젝트 파일 저장 기능은 구현·검증했으나 사용자의 이전 배치가 파일에 옮겨졌다고 표현하지 않는다. 기존 Chrome 화면에서 저장한 뒤 같은 주소로 새로고침하고 다시 저장하면 기존 형식을 프로젝트 정본으로 이관한다. 미저장 초안은 새로고침 전에 기존 저장이 필요하다.

정적 배포의 개인 저장은 브라우저 초안이며 전체 배포 반영은 로컬 파일 저장 → 커밋·push → 기존 배포 절차다. 원격 게시·Git 변경 게시를 실행하지 않았다. QA는 임시 파일과 격리 API로 실제 정본을 보존했다. 12레이어/131파라미터, 기존 iw-layers/1 형식을 재사용하며 다른 작품·시각 디자인·에셋은 변경하지 않았다.
