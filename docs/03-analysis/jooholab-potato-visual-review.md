## 검토 근거
docs/00·10·14, POTATO README/QA·프롬프트 카드01·app.js의 포인터/정지 처리·style.css의 캐릭터/그림자 분리, LAB README/QA-spatial과 전시 런타임/카메라 경로/매니페스트/모델 빌드 소스를 참고했다. bkit code-review의 심층 검토는 architecture-reviewer가 읽기 전용으로 담당했다. 레퍼런스 bruno-simon의 공간 발견/복귀, annamills의 이미지 중심 전시/텍스트 선택만 참고한다. 운전 물리·원작 이미지/브랜드·무드보드 편집은 이번 개선안에 필요 없다.

로컬 1440×900 외관·실내·하루 산책·POTATO·선비 및 POTATO play.html의 실제 화면을 비교했다. 캡처는 `.site-publish/jooholab-visual-review/`에 있다. Aside에서 DOM을 확인했지만 캡처 CDP 시간이 초과되어 사전 안내 후 별도 헤드리스 Playwright를 사용했다. 정지 화면은 reduced-motion 상태다. 전환의 시각 품질을 실제 재생으로 측정하거나 새 개선안을 검증한 것은 아니다. 첫 POTATO 캡처는 iframe 부모에 캐릭터 선택자를 사용해 실패했고, 실제 play.html에서 다시 캡처했다.

## 결론
전시관의 외부→문→실내→작품 이동과 수동 시점 변경은 실제3D를 유지할 이유가 있다(docs/14 §1 예외). POTATO에서 가져올 핵심은 조명/재질/원근이 잘 표현된 이미지, 역할이 분리된 그림자·움직임, 작은 포인터 반응이다. 공간은3D, 일부 투명 작품/소품은2.5D로 표현하는 조합이 적합하다. 모든 작품을 흔들거나 떠다니게 만들면 고정된 전시물의 공간감이 약해질 수 있다.

## 적용할 원칙과 레이어 계약
입장 경로·반전/취소·비율 보존·목록/키보드 대체는 기존 구현을 재사용한다. 과도한 카메라 흔들림·모든 이미지의 자동 움직임·공간 전체의 CSS 평면 대체는 적용하지 않는다. 작은 수정부터 진행하며 GLB 확장은 실제 요구가 생겼을 때 결정한다.

현재는 제안 단계라 레이어/파라미터 변경 없음. 구현 시 stage의 이동 속도/최소·최대 시간/페이지 전환 시간, artwork의 깊이·포인터 반응·그림자 강도, frame의 색/거칠기와 모델 제작 두께를 각 정본에 선언한다. 이미지/작품 목록은 콘텐츠이며 레이어는 표현만 맡는다. 고정 모델 치수는 재빌드 이유를 fixed에 기록한다. lint/probe는 이번에 새로 실행하지 않았으며 기존 PASS를 새 개선안의 검증으로 주장하지 않는다.

추천 실행 순서: 전환·속도 → 액자/종이/조명 비교 → POTATO 한 작품의 작은 깊이 반응 시제품. 예상 품질 향상은 제안이며 구현 후 같은 외관/실내/작품 화면과 실제 입력으로 검증해야 한다.
