# Blender 렌더 · 공간 재질 개선 계획

2026-10-02 · bkit Plan/Design/Do/Check/Act. 두 앱의 시각 품질 비교.

## 목적 · 범위
새벽 세 시는 기존 계산대 v2를 기준으로 같은 Blender 공간의 계산대/커피 정지 렌더를 시험한다. 더 사진처럼 보이지 않으면 기본 컷을 교체하지 않고 후보로 보관한다. JOOHO LAB은 실제 3D 이동을 유지하고 사진 PBR과 HDRI로 재질·빛을 개선한다. 결제·배포는 범위 밖이다.

## 참고 · 적용
docs/00·10·04·11, Dawn SPEC·seed story/theme·와이어프레임·assets/PROMPTS·README·QA, LAB README·QA·기존 plan/design을 읽었다. 기준 공간을 먼저 만들고 카메라를 파생한다. 기존 분기·시간·목록 대체 경로를 유지한다.
레퍼런스 bruno-simon: 공간 탐색과 명시적인 목록 대체 경로. everest: 카메라 경로와 모바일 렌더 비용 제한. 차량·등반 HUD·1,000장 시퀀스는 적용하지 않는다. Dawn은 상호작용 변경이 없어 새로운 외부 패턴 해당 없음.

## 구현 · 검증
1. 공유 CC0 사진 재질/HDRI와 출처/MD5 보관 → 16파일 무결성.
2. Dawn Cycles 동일 공간의 두 후보 컷 → 실제 이미지 검수, pack된 Blender 원본.
3. LAB 사진 재질/빛 → Detail UV1과 그림자 UV0 분리, GLB 6MB 이하, 실제 renderer 반영.
4. 두 앱 check/build, 입력·이동·되돌림·모바일·동작 줄이기 검수, QA/프롬프트 보관함 갱신.

## 레이어 계약
LAB stage: 기존 카메라·빛·색·거칠기·유리·물, 추가 groundTint/occlusion. 총 7층 53개 파라미터. 실제 renderer 값을 probe하며 공간/모바일 설정과 초기화 유지. 사진 스케일·UV·HDRI 파일·광원 위치·해상도는 소스 재현 좌표/성능 제약으로 fixed에 기록한다.
Dawn: 후보는 앱에 적용하지 않는 렌더 에셋으로 새 UI 층을 만들지 않는다. 기존 story media·Ken Burns·theme·작품편집 구조를 재사용하며 기존 layer-kit 미이관이 해결됐다고 표현하지 않는다.

## 설계 · 수정
Dawn: 물리 유리·금속·컵·영수증·진열 상품, Cycles/AgX/DOF. 정지 렌더를 영상이라고 표현하지 않는다.
LAB: 처음 단일 아틀라스는 근접 질감이 흐려서 사진은 미터 단위 반복 UV1, 접촉 그림자는 UV0로 분리했다. 최초 원본 JPEG 8.4MB 후보는 탈락, 1K 해상도를 유지한 인코딩으로 5,299,628B. 공식 r180 HDRLoader/MIT 사용. 첫 내부 이동 때 shader/buffer 준비 비용이 생겨 loading 동안 내부를 미리 준비한다.
Aside CDP 시간 초과가 반복되어 사용자에게 알린 후 설치된 Playwright headless로 검수 전환했다. 기존 시간 검사를 느슨하게 바꾸지 않는다. 결과는 두 앱 QA와 prompts 카드에 기록한다.

## 결과
Dawn 두 후보 렌더와 pack된 원본 완성, 기존 컷이 더 사진처럼 보여 기본 교체는 보류했다. LAB 최종 실제 브라우저 desktop 133/mobile 134/short-mobile 134 통과, 53파라미터 lint/probe·경로·GLB 예산 통과. 원본 출처·정확한 제작 요청과 한계를 prompts에 기록했다. bkit Plan/Design/Do/Check/Act 및 QA 기록 수행, 외부 배포는 하지 않았다.

## 후속 수정 · 깨끗한 건물 표면
사용자 피드백: 이전 인상이 더 좋고 새 건물은 얼룩덜룩하다. 자체 전후 외관 캡처를 기준으로 풍화된 석고와 작은 돌바닥 사진을 균일한 석재 재질로 교체한다. 넓은 얼룩·돌무늬 없이 미세 입자만 남기며, 기존 색·목재·이음새·HDRI·반사·AO를 재사용한다. 얼룩이 포함된 옛 색 베이크를 깨끗한 석재의 발광에 재사용하지 않는다. Blender 원본과 내보내기 스크립트도 맞춘다.
참고: docs/00·10·기존 계획/설계·README·QA, 자체 realism/photo 캡처. 상호작용 변경이 없어 새 외부 레퍼런스 해당 없음. 레이어 계약: stage 기존 53개 파라미터를 재사용하며 고정 미세 입자 지도는 재질 원본에 속한다. 새 레이어/설정 없음.
검증 순서: 재질 교체/GLB 6MB 예산 → 동일 시점 외관·실내 시각 검수 → 실제 이동/복귀·모바일·레이어 lint/probe → QA·에셋 카드 갱신. 이전 비교 캡처는 보존한다.

후속 결과: 균일한 석재와 노이즈를 제거한 접촉 AO 반영, GLB 4,357,584B. 모바일 390×844/390×600 각 134검사·53파라미터 probe 통과, 앱 check/build 통과. 데스크톱 첫 이동 시간 검사(8.5초)는 9.253초로 미통과이며 전체 회귀 PASS로 표시하지 않는다. Aside 시각 검수와 headless 자동검수 범위/한계는 LAB QA에 기록한다. 카드 18·로컬 보관함을 갱신한다.

## 후속 · 밝은 배경과 실내 품질
요구: 승인된 깨끗한 건물을 기준으로 배경을 밝히고 실내 완성도를 높인다. docs/00·10·04, LAB README/QA/기존 설계, 카드 18 캡처를 참고한다. 참고 패턴 색인을 확인했으며 새 상호작용이 없어 외부 카드 적용은 해당 없음. 기존 실내 동선·작품 데이터·밝은 석재를 재사용하고 큰 얼룩/과도한 풍화는 도입하지 않는다.
설계: 배경 이미지 밝기와 음영 조정, 밝은 자갈. 실내는 조절 가능한 따뜻한 전시 조명/간접광, 작품의 종이색 마운트, 직물 짜임·쿠션·책상 소품·매끄러운 조형물 곡면. 형상은 Blender 원본에서 재현하며 원래 카메라/입구/전시 좌표를 지킨다. UV가 달라진 옛 색 베이크를 재사용하지 않는 AO 중심 내보내기를 지원한다.
레이어 계약: landscape.brightness 추가와 shade 기본값 조정. stage.interiorLight/galleryLight/interiorTint 추가, groundTint 기본값 조정. 위치·스폿 조명 각도는 모델 설치 좌표로 fixed, 세기·색은 실제 renderer probe. 기존 53개에서 57개 파라미터. 문구 대비/모바일/장면별 설정·초기화 검수.
검증: 동일 외관/실내 캡처 → 모델 6MB/경로/모든 파라미터 lint·probe → 실제 입장/드래그/복귀 및 모바일 → 제작 카드·QA 기록. 데스크톱의 기존 이동 시간 실패는 기준을 낮추지 않고 재검사해 결과를 구분한다.

검수 수정: 실시간 전시 spot 7개는 데스크톱 이동 검사 12.273초로 탈락. Blender에서 실제 fixture 조명을 새 UV0에 32샘플·2048² 베이크/denoise하고 웹의 색·세기 uniform만 조절한다. 새 AO와 함께 재생성하므로 옛 색 베이크를 재사용하지 않는다. 이동 완료 시 두 번 그리던 동일 프레임을 한 번으로 줄인다. 조형물이 떠 보이지 않도록 실제 최저점과 받침 사이에 금속 고정 핀을 둔다.

결과: desktop 141/mobile 142/short-mobile 142 전체 검사 및 57/57 파라미터 probe 통과. 첫 입장 desktop 7.710초로 기존 8.5초 기준 통과. source와 runtime의 결과/미통과 후보를 LAB QA에 구분 기록한다. 최종 조명 지도 시각 검수에서 등기구 캡의 자기 가림을 발견해 광원 방출점을 12cm 앞으로 보정했다.
